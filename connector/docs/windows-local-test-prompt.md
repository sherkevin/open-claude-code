# Windows 内网连接器内部验收提示

版本：1.3.4（内部工程验收，不是客户操作手册）

本文件只供我方 Windows 测试人员使用。客户交付流程和帮助信息以 `docs/交付与运维说明.md` 为准；客户不需要运行 smoke 脚本、PowerShell 安装脚本或任何命令行测试。

## 1. 验收目标

验证 `kaiwu-connector-1.3.4-windows-amd64-setup.exe` 能否完成以下闭环：

1. 双击安装器后以中文欢迎页、进度页和完成页完成服务安装。
2. 完成页默认打开“开物内网连接器配置”本机页面，页面只监听 `127.0.0.1:17872`。
3. 在普通表单填写服务名称、MCP HTTP 地址、访问令牌，以及需要的 `appid`、`channel`、`userid` 和 HMAC 密钥。
4. 点击“读取工具列表”后，从真实 MCP 返回结果中勾选允许工具，不需要手工编写 MCP JSON。
5. 点击“保存并连接”后，页面分别显示内网 MCP、公网隧道和开物平台接入三个阶段的真实状态。
6. 保存、失败诊断和连接操作都不会泄漏访问令牌或 HMAC 密钥明文，也不会误删其他来源及其秘密。

## 2. 安装前检查

- 确认计算机是 64 位 Windows，并记录真实 Windows 版本。Windows 11 的通过不能写成 Windows Server 2019 已通过。
- 安装包必须是本次交付清单对应版本，文件哈希按发布目录的 `SHA256SUMS` 校验。
- 确认测试目录、配置备份和回滚方式；正式安装前不得删除已有客户数据目录。
- 使用独立测试 MCP，只绑定 `127.0.0.1`，不把测试端口开放到局域网或公网。

## 3. 图形化安装和配置

1. 双击 `kaiwu-connector-1.3.4-windows-amd64-setup.exe`，在正常用户账户控制提示中确认。
2. 安装完成后在完成页点击“打开本机配置页面”，或双击桌面的“开物内网连接器配置”。
3. 在“配置内部 MCP 服务”中填写普通表单：
   - 服务名称；
   - MCP HTTP 地址；
   - 访问令牌（如客户要求）；
   - 如客户要求华微动态签名，勾选并填写 `appid`、`channel`、`userid` 和 HMAC 密钥。`appid` 默认是 `MCP`，其他未知值不能猜测。
4. 点击“读取工具列表”，确认工具名称来自真实 MCP 的 `tools/list`，勾选允许工具。
5. 点击“保存并连接”，记录页面三个阶段的显示结果和实际失败信息。

## 4. 重点回归

- 更新已有来源时，其他来源、其他来源的访问令牌和 HMAC 配置必须保留。
- 访问令牌或 HMAC 密钥留空表示保留本机旧值，页面不能重新显示明文。
- 工具允许列表不能为空，不能使用 `*` 通配符绕过允许范围。
- 内网 MCP 检查失败时不能继续显示公网隧道或平台接入成功。
- 企业未绑定或企业集成凭据 K 未配置时，页面必须显示等待开物管理员，本地成功不能显示为平台已可使用。
- 高级区域可以保留原始 JSON、企业绑定、详细诊断和 Edge 预览，但正常首次接入不需要使用。
- Edge 预览不包含 `Authorization`，不能作为可直接导入开物平台的完整 MCP JSON。

## 5. 证据和边界

记录安装包 SHA-256、实际 Windows 版本、安装结果、页面截图、三阶段状态和脱敏诊断。Windows 11 实测、Windows Server 2019 兼容性、真实公网隧道、开物平台真实导入和真实业务工具调用必须分别记录，未执行的项目不能写成通过。
