# 开物内网连接器 Windows 快速开始

适用版本：<版本号>。支持目标为 Windows 11 x64、Windows Server 2019 x64；正式交付以开物提供的验收版本及企业 IT 批准为准。

## 已安装的用户

1. 收到经开物确认的安装包后，在原电脑双击安装，按企业 IT 要求确认管理员授权。已有企业绑定和业务配置无需主动删除或重新填写；升级后核对页面显示的企业及已保存服务。
2. 打开桌面的「开物内网连接器配置」。若此前提示平台配置权限不足，先联系开物技术支持。权限调整后，原页面可点击「重试生成 JSON」；如果已关闭页面，请先从「已保存的 MCP 服务」选择原服务。
3. 如确需远程协助，由企业管理员确认授权范围后，在「开物技术协助（远程 CMD 协助）」点击「开始协助」。工程师会在开物工作台中处理。协助完成后点击「停止协助」。若显示此设备尚未开通协助权限，请联系开物，不用重复安装；若已开通，仅刷新页面即可。开启后无需再次填写已有业务服务地址或访问凭据。

开启协助允许授权工程师在本机执行诊断和维护命令，可能涉及读取或修改文件。确认某个业务服务仅表示确认其业务接入范围，不等于限制全部命令行协助。请勿在不明授权范围的情况下开启协助。不要关闭终端安全防护或向群聊发送访问令牌、密码、完整连接配置或真实业务数据。

## 首次安装的用户

首次使用需填写开物单独签发的企业绑定码。打开「连接业务系统」，填写企业提供的业务服务地址，点击「读取工具」。如需认证，由企业 IT 或开物工程师按批准方式协助填写。选择允许开物使用的工具后点击「生成 MCP JSON」；配置的导入与业务调用由有权限的开物管理员完成。

如果显示业务服务已保存、开物平台尚未开通配置权限，说明需要开物技术支持核对平台权限，不需要您重新填写地址或重新安装。页面的「查看协助方式」只会定位到协助界面，不会自动授权或开始远程操作。

## 连接测试与诊断

点击右上方「连接测试与诊断」，可运行内置测试，不需要准备业务服务。出现异常时，请联系开物并提供页面上的诊断编号（如有），无需自行收集 HTTP 报文。

连接器只主动连接开物批准的公网服务，不要求客户开放入站端口。涉及企业代理、网络访问策略或安装授权时，由企业 IT 配合处理。

## 开物交付人员须知

- 核实企业、设备与具体服务的接入授权。设备配置导出失败时，使用控制面的只读状态接口核查许可和最近拒绝原因，不得为排查而扩大权限。
- 客户实际业务接入以开物平台成功调用获准的只读工具、核对正确结果为准；仅通过示例测试或读取工具列表不代表交付完成。
- 正式交付前核对组织代码签名、安装包 SHA-256、覆盖升级、配置保留、回滚和企业 IT 授权；禁止以关闭防护作为安装条件。
- 可选的第三方远程支持门户通过 KAIWU_SUPPORT_PORTAL_URL 配置固定 HTTPS 页面。通用包默认留空并隐藏该备用入口；它与内置「开物技术协助」不是同一功能。


### 已获授权的本机查询复现（技术人员）

连接器已保存服务的情况下，可以使用本机安装的连接器程序执行一次直接只读诊断。必须指定该服务的来源编号以及已选择的 query 或 describe 工具；只测试经过业务方批准的只读参数，不测试 call，不修改生产记录。参数可通过本机 JSON 文件传入（最大 16 KiB），例如：

    kaiwu-connector.exe diagnose --source <已保存来源编号> --probe query --probe-args-file <参数文件路径>

该命令通过本机受保护配置复用地址、静态认证头或动态认证配置，发起新的 MCP 会话；不要求复制、打印或上传原始凭据，不回传业务记录正文。诊断报告显示工具成功/失败、HTTP 状态、可识别的脱敏错误码和请求编号。HTTP 200 且工具 isError=true 仍为失败。由于会话编号和动态签名按请求生成，这是等价业务请求的独立复现，不是原始字节流重放。协助期间应仅在企业管理员批准的范围内由工程师操作，完成后结束协助。
