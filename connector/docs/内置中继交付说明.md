# 开物内网连接器 Windows 快速开始

此安装包面向 Windows 11 x64 和 Windows Server 2019 x64。连接器和中继客户端都已编译进安装包。

1. 双击安装包，确认 Windows 管理员授权。安装后会打开配置页。首次使用填写开物签发的企业绑定码。之后也可从桌面打开「开物内网连接器配置」。
2. 如由开物工程师接入，请保持配置页打开。收到「开物协助接入」请求后，核对服务名称和地址，再点击「开始协助」。工程师会在开物后台完成测试和导入。需要结束时，在同一个位置点击「停止协助」。
3. 如自行接入，在「接入本机 MCP」填写端口或完整地址，点击「读取工具」。例如填 `3000` 会使用 `http://127.0.0.1:3000/mcp`。服务要求令牌或华微动态签名时，在「服务名称和认证」填写。勾选允许使用的工具，点击「生成 MCP JSON」，然后在开物的「MCP → 导入配置」粘贴并测试连接。

若只想检查连通性，点击页面右上方的「连接测试与诊断」，运行内置测试，无需准备业务 MCP。

连接器从 Windows 主动连接开物控制面，客户网络只需允许批准的出站路径。浏览器能打开开物网页后，如果连接器仍离线，请让 IT 检查 Windows 服务的出站代理是否允许连接开物域名的加密 WebSocket。安装或连接失败时，记录界面上的诊断编号并联系开物支持。
