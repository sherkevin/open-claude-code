# 动态认证与受控试装说明

版本：1.3.10 内部验收候选

## 1. 作用

华微业务 MCP 的 `tools/call` 不仅需要固定 Bearer，还需要与渠道用户绑定的动态身份头和 HMAC 签名。连接器不允许云端、Edge、模型或浏览器直接生成这些头，而是由客户 Windows 主机上的回环认证代理生成。

每个来源独立监听 `127.0.0.1` 的临时端口。frpc 只连接这个回环端口，认证代理再连接导入时固定的客户 MCP 地址。代理不提供任意目标转发，也不接受非 MCP 方法。

## 2. 本机需填写的字段

| 字段 | 来源 | 是否允许出现在平台 |
| --- | --- | --- |
| `appid` | 华微提供的渠道应用身份 | 否 |
| `channel` | 华微渠道编码 | 否 |
| `userid` | 华微已批准并映射的渠道用户 | 否 |
| HMAC 密钥 | 华微现有协议使用的实际密钥；只要求非空，不额外要求 16 字节 | 否 |
| 工具允许列表 | 客户书面批准的最小只读工具集合 | 可以显示名称；不能由平台扩大 |

客户正常在本机页面的“配置业务 MCP 服务”普通表单中填写固定 Bearer、`appid`、`channel`、`userid`、HMAC 密钥，并通过“读取工具列表”勾选允许工具；不需要手工编写或导入 MCP JSON。原始 `mcpServers` JSON 导入保留在高级选项中，只用于已有标准配置的维护场景。Bearer、动态认证配置和工具允许列表都只保存在连接器本机数据目录。

## 3. 请求规则

| MCP 方法 | 固定 Bearer | 动态身份与签名 | 工具允许列表 |
| --- | --- | --- | --- |
| `initialize` | 是 | 否 | 不适用 |
| `notifications/initialized` | 是 | 否 | 不适用 |
| `tools/list` | 是 | 否 | 响应按允许列表过滤 |
| `ping` | 是 | 否 | 不适用 |
| `tools/call` | 是 | 是 | 调用前强制检查 |

其他方法、JSON-RPC 批量数组、任意路径和不在允许列表内的工具均在连接器本地拒绝，不触达客户 MCP。

## 4. HMAC-SHA256 算例

每一次转发的 `tools/call` 都重新生成 UUID v4 的 `requestId` 和 UTC Unix 秒 `timestamp`。

签名原文固定为：

```text
appid=<appid>&channel=<channel>&userid=<userid>&requestId=<uuid>&timestamp=<unix-seconds>
```

使用 UTF-8 字节和 HMAC 密钥计算 HMAC-SHA256，`sign` 使用小写十六进制。代理最终发送：

```text
Authorization: Bearer <客户固定 Bearer>
appid: <appid>
channel: <channel>
userid: <userid>
requestId: <uuid>
timestamp: <unix-seconds>
sign: <hex>
```

连接器不对网络结果不确定的 `tools/call` 自动重试。上层如决定重试，必须产生新的 `requestId`、`timestamp` 和 `sign`。

## 5. 自动化验证范围

已覆盖的合成测试：

- 固定 Bearer 由代理注入，平台入口头不会到达上游；
- `initialize` 能力只向平台暴露 `tools`；
- `tools/list` 同时过滤 JSON 和增量 SSE 结果，多行 `data` 只输出一个有效载荷；
- 允许工具可调用，不允许工具在本地返回 `403 POLICY_DENIED`；
- HMAC 原文顺序、UTC 时间戳、UUID v4 和签名值可被独立校验器验证；
- 上游重定向被拒绝；
- 上游会话编号映射为连接器自己的不透明会话编号；
- 认证状态接口和状态快照不返回 Bearer、HMAC 密钥。

## 6. 仍需客户环境验证

以下内容不能用合成测试代替：

- 华微实际 `tools/call` 签名校验器是否接受连接器算法；
- 华微服务端的 `requestId` 唯一性和时间窗口规则；
- 客户 Windows Server 2019 上的服务、ACL、整机重启和安全软件行为；
- 客户测试 Bearer、HMAC 密钥、渠道身份和真实只读工具；
- 真实错误凭据、专属 frps／visitor、Edge、断线恢复和撤销链路。

连接器向控制面登记来源时，会通过本机认证代理读取真实的 `tools/list`，对获准工具的规范化名称、描述、输入/输出 schema、注解和服务端版本计算 `tool_schema_sha256`。摘要是 schema 语义指纹，不是工具名称列表的哈希；候选工具缺失、目录重名或无法读取目录时拒绝登记。

在上述项目完成前，1.3.6 只能称为“企业统一入口候选版本”，不能称为客户业务已验收。
