# HippoRAG 公开工业资料 Pilot v0.1 诊断集

状态：`frozen_diagnostic_pilot_not_holdout`。2026-11-10 由助手从已有 NIST 原文编制，经另一助手与主会话来源复核后，在任何真实模型调用前冻结；q06 已消除“完整 LAN 设备清单”的歧义。冻结时没有真实模型调用或质量分数。不是独立人工 gold，也不是客户案例或交付验收集。

## 文件边界

- `passages.jsonl`：18 段未改写英文原文，共 12,107 字符，来自 NIST IR 8227 和 SP 800-82r3 的 12 个物理页。
- `images.json`：只引用已有的两张 NIST 图片，不重复复制。SCADA 图是图文证据，目录页是困难负例，不用于冒充设备图片语义。
- `evaluation/questions.jsonl`：八道助手编写的跨段/图文问题、答案和必需证据。仅离线评测使用，统一作为冻结的诊断集，不声称独立留出集。
- `evaluation/expectations.json`：21 个实体、87 处已复核的别名提及、十条有原文证据的关系，以及六个本轮目视定位的图片实体框。不是穷尽标注；未标出的真实实体不能因此算错。
- `source-manifest.json`：原始 PDF/图片 SHA-256、抽取器、页码、文本区间及文件摘要。
- `verify_sources.py`：无模型的来源完整性检查。它验证原文与坐标绑定，不判断标注质量，也不执行检索。

只允许 `passages.jsonl` 的原文及来源字段、`images.json` 指向的图片进入索引；不可将 `evaluation/` 的答案、实体别名、关系预期、问题批次或复核意见拼进抽取提示词。后续检索只发送正在评测的单个问题。此目录没有推理运行器，不会自动上传或调用供应商。

不要把以上所有题都统计为严格多跳图推理：`kind` 已区分证据组合、实体桥接、流程组合和图文桥接。第二复核应确认问题不歧义、两项证据均必要，并识别其他同样充分的证据组合；不能只因未命中指定片段就判错。全部问题是助手编制而非用户真实流量。

实体作用域区分 IR 8227 的 CRS 实例与 SP 800-82r3 的通用 SCADA 示例，不能因同名 PLC 自动合并为同一台设备。图关系使用 `depicts_inside`，只表示图中位置；不代表真实客户装置的物理连接。

本轮发现既有 v2 标注的 HMI/Control Center 等框与当前全页图错位，未复制这些旧框。本目录六个框以当前 1020×1320 像素图目视重定，格式为左上角 x/y 和宽/高，已二次目视复核，不称为分割掩码。字段完整性通过也不能证明框的语义正确。

## 可复现位置

抽取命令为 `pdftotext -enc UTF-8 -f N -l N SOURCE -`，当前固定版本 `22.02.0`；只移除输出中的 U+000C，不折叠空格、换行或改写原文。`physical_page` 从 1 开始，另存印刷页码。`char_start/char_end` 是规范页文本中的 Unicode 字符半开区间；`page_text_sha256` 锁定抽取结果。页抽取器版本变化时先复核，不能静默改摘要以通过。

```bash
python3 fixtures/hipporag-public-pilot-v1/verify_sources.py
```

程序只读取项目内登记的公开资料并调用本地 `pdftotext`，输出 `source-integrity-only`。不联网、不读取模型配置、不调用模型、不重启服务。

后续正式质量验证需要扩充无答案/负例题、冻结分组、独立复核与更大语料。当前八题没有无答案题，不能据此推断幻觉率。公开文件许可和适用范围沿用原始目录，不能据此将文档内容当作生产操作指令。

## 冻结说明

本轮只报告不穷尽标注的实体召回、指定证据集合召回和图文诊断结果；不把未标出的实体算成错误，不报告未审查的精确率，不把八道组合题都称为严格图多跳。CRS/CRS workcell 是合法别名，不要求模型从没有展开定义的片段猜出英文全称。没有无答案题，不能据此推断幻觉率。复核人员均为助手，不是独立客户或人工验收。后续扩大评测需另起版本，不能根据本次输出改动冻结答案。

预推理文字校正：q05 的原文是研究警告，不是法律或监管禁令。本批 21 个实体标注并不覆盖答案内全部实体，例如控制服务器没有独立标注；其召回率不能作为全部知识实体的召回率。
