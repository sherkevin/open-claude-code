# 工业公开知识库样例（industrial-public-v1）

这是用于本地开发和验收的公开资料样例，不包含华微世纪或任何客户数据。文件来自美国国家标准与技术研究院（NIST）、美国职业安全与健康管理局（OSHA）和中国政府网公开政策页面，保留原始来源、检索日期、许可边界和 SHA-256。NIST 在美国境内的技术出版物通常不受版权保护，但仍保留署名和原始链接；政府法规和政策文件正式使用前应再次核对页面和辖区适用性。

## 已下载资料

- `documents/nist-sp-800-82r3.pdf`：操作技术安全指南（2023），覆盖工业控制系统、可编程逻辑控制器、分布式控制系统、监控与数据采集系统、风险和安全架构。
- `documents/nist-ir-8183.pdf`：制造业网络安全框架画像（2019 更新），覆盖制造业任务目标、识别、保护、检测、响应、恢复和安全目标。
- `documents/nist-ir-8219.pdf`：制造业工业控制系统行为异常检测（2020），覆盖机器人工作单元、过程控制系统、异常检测和安全控制映射。
- `documents/nist-ir-8227.pdf`：机器人工作单元制造业画像实施方法（2019），覆盖协作机器人、测试床、测量方法和性能影响分析。
- `documents/osha-1910-212.md`：机器防护法规的结构化公开摘要，便于实体抽取和来源核验；完整法规以 OSHA 原页面为准。
- `documents/smart-manufacturing-standards-2024.pdf`：中国政府网公开的国家智能制造标准体系建设指南（2024版），补充中文制造业标准体系、装备和工业软件语境。

## 使用边界

1. 这些文件只用于本地示例和验收，不代表客户工厂的规定，也不能替代法律、标准或安全工程审查。
2. PDF 原件可直接通过知识库上传接口导入；导入后必须保留文档版本和 SHA-256。图谱实体来自文本解析和确定性规则，关系目前只是同段共现，不能宣称完成语义关系抽取。
3. `source-catalog.json` 同时记录暂未下载的官方资料清单。新增资料须先确认来源、许可、大小、摘要和哈希，再放入仓库；禁止自动抓取登录页、客户网页或版权不明的全文。

## 验收重点

`entity-acceptance.json` 对标准号、设备标识、工艺、材料、质量指标和组织等实体给出可复现的期望值。验收要检查：

- 节点 `kind` 是否可解释（`standard`、`equipment`、`process`、`material`、`metric`、`organization`）；
- 节点来源是否有文档、版本、页码和字符偏移；
- 未配置视觉模型时，图片实体状态仍为 `needs_model`，不伪造像素实体。
