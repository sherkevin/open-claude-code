# 华微公司知识库 fixture

这是学校云分支 `oc-huawi-company-kb` 的可复现、脱敏样例，不是生产数据目录。

- `manifest.json`：来源清单、纳入/排除原因、媒体预览和图谱质量门槛。
- `documents/`：本地检索用的清洗文本；不包含飞书内部链接、白板标记和手机号码。
- `media/`：PPTX 页面预览，属于页面证据，不是视觉向量。
- `graph/`：人工复核实体和关系种子；规则候选仍需人工复核。

原始归档 `huawi-source-materials/` 未提交到 Git。群聊图片附件没有取得原始二进制，
因此该 fixture 不伪造对应图片实体。视觉语义索引目前为 `needs_model`，只有在学校云
配置并验证授权模型后才能升级状态。
