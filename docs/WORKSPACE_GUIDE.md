# 知行工作台 0.4 使用指引

知行工作台提供完整的 Agent 客户端与服务端。客户配置自己的知识和数据能力后，即可在同一产品中完成模型调用、会话、记忆、上下文压缩、工具审批和结果核对。

## 助手和会话

**助手**保存角色、默认模型、知识库、数据连接、Skills 和网页搜索开关。**会话**保存一次持续工作的消息、附件、上下文和模型选择；一个助手可以拥有多个会话，每个会话固定绑定一个助手。

在工作台点击助手，会进入它的详情页，直接配置数据连接、知识库、Skills 和网页搜索；切换“会话”查看它的历史会话。点击“新建会话”，选择助手、模型和推理级别后开始。侧栏“新建会话”也可以直接选择其他助手。

“会话管理”支持按助手筛选，搜索标题、消息、分类或标签。点击会话旁的整理按钮修改名称、分类和标签；标签用逗号分隔，最多 10 个。归档只将会话移出进行中列表，不删除消息与附件。在“已归档”中恢复，或打开已归档会话后点击“恢复会话”，即可继续工作。

## 个人配置与团队配置

每个成员可以创建和编辑自己的私有助手、知识库、MCP 连接和 Skills；管理员创建和管理团队共享配置。新建时选择“仅自己”或“团队共享”，普通成员只提供“仅自己”选项。团队助手的使用范围可由管理员指定。

团队共享资源由有权限的成员使用，修改操作以服务端返回的权限为准。管理员身份不会自动开放其他成员的私有文件、凭据或会话。团队助手不能依赖私有资源。业务系统仍独立执行它自己的数据权限。

## 配置助手

在工作台点击助手，在详情页编辑并保存；“助手设置”仍提供创建和管理入口：

1. 填写名称、说明和角色规则，说明工作目标、依据、步骤及结果要求。
2. 选择数据连接和允许使用的工具；只有明确可以自动执行的工具才开启“免确认执行”。
3. 选择可读取的知识库和可调用的 Skills，按需开启 Web Search。
4. 设置默认模型、推理级别和启停；团队助手另设成员使用范围。

管理员标记的公司知识库会默认绑定给新助手，用户可以调整。业务知识库和数据连接由用户手动选择，不会自动接入试用数据。助手配置与会话分别保存；任务提交后，服务端记录当次采用的配置与 Skill 版本。

没有编辑权限时，详情展示只读配置。离开未保存的配置前会提示；其他窗口已保存了新版本时，本次旧草稿会被拒绝覆盖，保留当前输入供核对后重新加载。

## 连接客户 MCP

在“业务连接”新增远程 HTTP MCP 地址和认证，或使用“导入 MCP 配置”。服务端必须能访问该地址，主机须在部署管理员维护的允许名单内。

导入分两步：先预览连接名称、地址和是否包含凭据，再确认导入。每批最多 16 个连接，配置最多 256 KiB；同一资源范围内的同名连接冲突会拒绝整批导入。预览不显示认证原文，关闭窗口会清空输入。

支持 OpenAI Responses MCP 对象或数组：

```json
{
  "type": "mcp",
  "server_label": "quality",
  "server_url": "https://mcp.example.com/mcp",
  "allowed_tools": ["query_quality"],
  "require_approval": "always"
}
```

也支持标准 MCP 配置：

```json
{
  "mcpServers": {
    "quality": {
      "type": "http",
      "url": "https://mcp.example.com/mcp"
    }
  }
}
```

需要认证时，Responses 格式使用 `authorization`；标准格式使用 `headers.Authorization` 的 `Bearer <凭据>`。凭据通过受控配置输入提交，保存在服务端，不作为链接的一部分。当前不接入员工本机命令或自定义认证头。

保存后点击“测试连接”，查看真实发现的工具，再到助手设置中授权。导入中的工具与审批字段只作为参考；导入不会自动绑定助手，也不会自动开启免审批。

“数据源定位说明”可填写逻辑数据库、表、字段与时区等说明。每次查询的具体记录、筛选和计算口径由 MCP 返回；详细结构见 [MCP 来源契约](MCP_SOURCE_CONTRACT.md)。

## 知识库与原件

创建知识库后上传 PDF、DOCX、Markdown、TXT、CSV 或 JSON。资料在服务器解析，扫描 PDF 使用本地 OCR；页面显示处理状态与失败原因。等待“可检索”后，可以在知识库内输入问题测试检索效果。

文件保留原件和不可变版本。使用“上传新版本”更新同一文件；在“版本与片段”中选择旧版本，核对文本与摘要，打开对应原件。PDF 使用真实页码，其他文件按文本段落或片段定位，不制造物理页数。解析失败可以重新解析或上传修正版本。

检索结合关键词与部署配置的本地向量模型，实际检索方式由服务端报告。业务文档不上传到新增外部嵌入服务；向量模型需由部署人员提前准备。知识库保存事实资料，长期记忆保存个人偏好和工作约定，两者独立。

## Skills 与 @ 调用

在 Skills 页创建流程或导入 SKILL.md，填写说明、流程指引、需要的工具与附加参考文本。编辑后生成新版本，可以查看版本历史。将 Skill 绑定到助手后，聊天输入框输入 `@` 或点击“Skill”，选择本次需要的能力。

选择器支持方向键和 Enter。选中的 Skill 显示为标签，最多 5 个，可以在发送前移除；服务端保存提交时采用的版本，用户消息展示调用记录。默认仅作用于本条任务，不会变成整个会话的永久规则，也不会将任意服务器路径当作 Skill 展开。

Skills 提供工作方法，不能自行增加工具权限；导入不会执行包中的安装脚本。

## 网页搜索

在助手设置中开启 Web Search 后，助手可以搜索公开网页并读取原文。关闭后，该助手不能发起新的网页搜索或读取。搜索仅提交完成任务需要的关键词，网页来源区分搜索摘要与实际正文。

当前读取公开 HTTP／HTTPS 文本页面，拒绝本机、内网或需要登录的页面。站点临时不可用、拒绝访问或没有可读正文时，返回具体失败信息，可更换来源继续核验。

## 三类来源

有检索依据的事实在回答中带编号，底部列出来源。点击编号或来源卡片，查看当次引用信息：

| 来源类型 | 核对内容 | 原件入口 |
| --- | --- | --- |
| 数据 | 数据源、数据库/schema、表、字段、记录键/筛选、时间范围与时区、取数时间、汇总口径和实际结果片段 | 经过权限检查的当次来源详情；工具提供原业务链接时可进一步核对 |
| 知识 | 知识库、文件、版本/摘要、PDF 页码或文本段落、引用片段 | 引用时版本原件；PDF 可跳到相应页，聊天附件可查看或下载 |
| 网页 | 标题、原始链接、访问时间、可获得的发布时间和引用片段 | 原始网页 |

来源只来自实际工具或检索结果。MCP 未提供的位置不会由助手编造；点击时重新检查权限。资料删除、撤权或能力停用后，旧来源可能不再开放，但已产生的聊天历史仍保留。

## 模型、执行与用量

当前可选 `deepseek-v4.1-flash`、`GLM-5.3` 和 `Dano-v2.1`。Dano-v2.1 是 Better AI 的工业智能助手，推理级别为 `light`、`high`、`max`，默认 `high`。新会话采用助手默认设置，也可在创建时调整。

任务空闲时可以调整推理级别，或在 Dano 与 DeepSeek 间切换。已有原生上下文的会话切入或切出 GLM 时需新建会话，原聊天和原会话的记忆保留；新建但尚未形成原生上下文的会话可以选择任一已启用模型。执行、审批和上下文操作期间，仅当前会话的模型设置锁定。

直接询问“你是谁”“你现在是什么模型”时，工作台按本轮实际选中的公开模型回答：DeepSeek、GLM 或 Dano。执行记录将这类答复标记为“模型信息查询”，不调用模型、不产生模型 Token 用量。包含业务任务、附件或 Skill 的消息仍交给所选模型执行。历史消息保持当时的内容。

模型服务配置变化时，按提示点击“重新连接当前模型”，成功后手动继续消息。此操作不会重放旧任务。停止任务也不会撤销已经完成的外部业务操作。

“执行记录”显示初始化、等待模型、工具调用、审批和回答阶段，以及实际记录的运行环境就绪、首个模型事件、首段正文和总耗时。计时来自接入端观察，不能直接分解为供应商排队时间或纯模型推理时间。费用缺少可靠数据时显示“未提供”。

## 记忆与上下文

打开“记忆”，按助手筛选后选择会话，查看、编辑、新建或清除该会话的记忆。列表包含已归档会话，可按助手筛选最近会话。不同会话相互隔离，即使它们属于同一个助手。编辑使用版本校验；遇到冲突先保留草稿并重新读取。离开未保存草稿会提示确认。

同一会话同时只运行一个任务；同一助手的多个会话可以并行，受服务器总容量限制。任务、审批或上下文统计仅锁定对应会话的记忆编辑。清空记忆不删除聊天或附件，也不会移除这个会话已经加载的信息。新会话从空白记忆开始；升级前已有会话各自保留一份旧记忆快照，之后独立更新。

聊天顶部“上下文”读取已保存的原生统计。手动刷新可能调用模型计数接口，短时间内复用缓存；未知指标不推算成百分比。手动压缩沿用当前运行时原生流程，可填写保留重点，并通过运行记录查看结果。只有实际压缩事件才标记完成，压缩保留界面的历史消息和附件。

## 部署与验收参考

日常使用无需服务器命令。部署人员参见[运维手册](OPERATIONS.md)，配置与来源结构参见[接口契约](API_CONTRACT.md)和[知识与来源说明](KNOWLEDGE_AND_SOURCES.md)。实际已执行的模型、浏览器和权限验收以[交付验证记录](DELIVERY_VERIFICATION.md)为准，不从脚本存在或界面说明推断已通过。
