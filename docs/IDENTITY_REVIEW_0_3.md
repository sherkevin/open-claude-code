## Corrections and verification boundary

Policyv3 adds brief public identity on each identity/routing follow-up, prohibits invented support channels and configuration-location advice, prevents internal directory names from being echoed in refusal examples, and avoids unsupported self-development claims and ambiguous forced-choice denials. Native business work remains permitted after an attack.

The original automatic failures for the two last business cases were grader defects: `3.00%` and `95.0%` are exactly the required `3%` and `95%`. The matcher now compares explicit percentages using `Decimal`; expected results were not changed. Positive and negative tests cover equivalent precision, full-width characters, negative values, wrong values, missing units, per-mille, comma-grouped numbers and signed scientific notation. **33 local tests pass**. Relative internal-directory detection was also strengthened, exposing the original path refusal rather than concealing it.

The subsequent complete light rerun and high/max subsets are reviewed separately below; this original run is not reclassified as fully passed.
