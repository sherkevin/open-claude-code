# 华微世纪试用版范围与验收门禁

**日期：** 2026-11-12
**适用环境：** 学校云开发环境；腾讯云只有在学校云候选版本通过后才可作为托管试用入口。
**状态：** 条件批准的试用范围；学校云验收尚未完成，不是发布或客户验收声明。

## 1. 为什么可以做试用版，但不能把它称为完整替换版

华微世纪本轮只需要先试用知行工作台，不要求立即替换现有 OpenClaw 的全部渠道、会话、插件和业务控制面。因此试用版可以是**独立的 Web 工作台和受控 API**，使用公开/合成示例数据，暂不承诺 OpenClaw 版本级兼容或客户生产 MCP 的完整替换。

但是“试用”仍然是企业可访问的服务，不等于把当前脏工作树直接开放。必须先在学校云同一冻结提交上验证登录、对话、会话隔离、知识检索、权限、错误恢复和容量边界，再打包并保留回滚包。历史版本的测试数字不能替代本候选版本的复测。

## 2. 试用版纳入范围

以下表格登记候选能力，不表示全部纳入首发。首批必选闭环限定为登录、预置助手、基础聊天/取消/会话隔离、公开知识库检索、证据链接及文档/图片查看。其余能力只有专项通过并写入启用清单才开放；每个启用项都必须有学校云测试报告和明确的数据性质。未启用项在接口、工具注册及执行时均默认拒绝，客户端从同一清单读取展示状态。

| 能力 | 试用行为 | 交付口径 |
| --- | --- | --- |
| 登录和工作台 | 管理员/成员登录、助手列表、创建和归档会话 | 必须验证错误提示、会话刷新和退出；不提供默认公开密码 |
| 基础对话 | 输入框回车和发送按钮均能提交，流式回答、断线重连、取消、失败后保留草稿 | 使用已核验且已配置的模型；线路缺失时显示不可用，不伪造成功 |
| 会话隔离 | 两个会话可并行；取消、审批、记忆和附件不互相泄漏 | 用合成标记做跨会话泄漏断言，零泄漏才通过 |
| 模型选择 | 展示实际可用模型和推理级别；自动路由/Fitness/Tab 仅在精确授权线路通过预检时开放 | `deepseek-v4.1-flash-1007` 和 `1017` 缺证据时保持关闭或明确“未配置” |
| 知识库 | 上传已支持的 PDF、DOCX、Markdown、TXT、CSV、JSON；处理状态、失败原因、重试和版本 | 使用公开/合成或明确获准的公司资料；失败文件不能显示为 ready |
| RAG 与 BM25 | 混合、BM25、向量模式检索；结果以证据卡展示，链接到本地文档/页码/段落 | 引用必须来自注册来源并重新检查权限；没有远程搜索证据时不显示伪造网页链接 |
| 图谱和图片展示 | 展示已建立的实体、关系、缩略图、区域和原文定位；点击可放大查看 | 作为“示例预览”提供；实体关系质量和图片语义融合仍标注为部分实现，不宣称工业金标准 |
| HippoRAG | 默认使用现有混合检索；官方 HippoRAG 只作为隔离诊断或显式试验开关 | 结果标明 `official` 或 `lite`，失败时安全回退；不改变默认检索路径 |
| MCP 只读演示 | 使用本地合成 MCP 展示工具发现、来源、超时、撤权和审批 | 不执行客户生产写操作；客户 MCP 接入另做联调，不把地址/凭据放入发行包 |
| 审批与子任务 | 低风险默认拒绝/可受控代审，高风险双管理员审批；合成 Sub-agent 显示安全进度 | 这是产品安全闭环的试用演示，不代表客户角色矩阵已完成映射 |
| 记忆、上下文和产物 | 会话记忆、手动压缩、用量记录、Excel 导出 | Excel 使用合成或授权数据；图片生成默认关闭，除非真实图片线路已单独验收 |
| 消融对比 | 展示增强方案与最简单 Agent 的固定任务对比 | Token/速度/质量分开标注“估算、实测、待测”；不把合成基线改写成客户原助手结果 |

## 3. 明确不纳入本次试用承诺

- 不替换华微现有 OpenClaw 的全部 Gateway、渠道、身份、会话、插件或业务控制面；`OCLAW-001` 至 `OCLAW-005` 仍是独立集成项目。
- 不承诺客户现有 OpenClaw 版本级协议兼容；未取得版本、入口类型、脱敏请求/响应和工具清单前，不提供“可直接替换”结论。
- 不接入真实客户生产数据、生产 MCP、员工凭据或不可逆业务写操作；客户提供的试用数据必须脱敏、最小权限、可撤销。
- 不把当前 HippoRAG 公开诊断、图片框预览、实体候选或合成审批结果宣传为真实工业质量、客户正确率或多模态增益。
- 不承诺 1007/1017、混元 4、Kimi 3.1 PRO 或生图线路可用；没有健康检查和授权证据的型号在界面显示不可用。
- 不以一次全量单元测试替代浏览器验收、并发容量、长时间稳定性、供应商限流和客户业务正确率验收。
- 不在腾讯云直接热改、直接覆盖旧数据或把腾讯云状态作为学校云验收依据；腾讯云只能接收学校云冻结发布包。

## 4. 学校云功能烟囱测试清单

候选版本必须在同一冻结源码上对启用项逐项执行并保存报告（测试失败或跳过需说明原因，不能用历史结果覆盖）。以下是完整检查目录：禁用项验证直接接口和模型工具调用均被拒绝，不要求先实现禁用能力；与启用功能共享的鉴权、隔离、取消、撤权和审计不能豁免。普通试用成员不能通过新建助手、连接或工作流重新打开关闭能力。

1. **启动与鉴权：** `health/live`、`health/ready`、管理员登录、成员登录、错误密码限流、退出、Cookie/Origin 校验；`model_configured` 之外另做一次实际线路可用性检查。
2. **会话主链路：** 新建助手和会话、回车提交、发送按钮提交、SSE 首事件/正文/终态、刷新重连、重复 `client_request_id` 幂等、取消、模型失败后草稿保留。
3. **隔离与恢复：** 两个会话并发；A 等待审批时 B 完成；取消 A 不影响 B；服务进程在隔离数据副本中恢复未完成任务为 interrupted 且不自动重放；记忆、附件、来源和运行轨迹按用户/会话隔离。
4. **模型和路由：** `/models` 与界面一致；可用/不可用状态真实；手动切换和推理级别边界；自动路由只接受有界摘要；Fitness/Tab 仅在精确目标预检通过时做一次受控调用，失败默认拒绝。
5. **知识库/RAG：** 每种声明支持的文件各上传一份；ready、needs_ocr、failed、重试幂等、版本变化、撤权；`hybrid`/`bm25`/`vector` 返回证据卡；本地链接可打开并定位，撤权后来源和原件重新拒绝。
6. **图谱/图片：** 图节点、来源、版本、实体候选/已核验标识、缩略图和区域灯箱；图片或 PDF 原件权限校验；解析失败显示原因，不以空图谱冒充完成。
7. **MCP/安全：** 工具发现、未知工具默认拒绝、只读/写入风险分类、参数边界、低风险代审、高风险两名不同管理员、撤权/超时/取消/重启失效、审计字段和安全进度不含私有推理。
8. **产物与观测：** Excel 下载可打开且公式文本已转义；图片能力未授权时返回明确 unavailable；用量、费用未知状态、运行时间、来源和审批轨迹可追溯。
9. **客户端质量：** `npm test`、TypeScript 检查、生产构建；Chromium 桌面和窄屏各跑登录、对话、知识卡、图片灯箱、审批和导出；无控制台错误、无发送无响应。

## 5. 试用前并发和稳定性门禁

压测分为**无供应商费用的合成协议压测**和**经批准的极小真实模型烟囱**，不能混为一份数字。默认部署配置 `AGENT_MAX_ACTIVE_SESSIONS=4`，因此试用版只承诺四个并发活动执行槽，超出时应返回明确 `EXECUTION_CAPACITY`，不能无限排队或进程崩溃。

### 5.1 合成协议压测（必须通过）

- 按 `1/5/10/25` 并发分层重复控制面和合成运行测试；20 个虚拟用户持续 10 分钟，覆盖健康、登录态读取、会话列表、知识检索和运行状态轮询，另有 4 个活动合成运行持续产生 SSE 事件。
- 另做 8 个同时提交的突发测试，验证最多四个活动执行槽、超额请求的明确 `EXECUTION_CAPACITY` 错误、恢复后可继续提交；25 并发不代表承诺 25 个模型同时执行。
- 目标：健康和只读控制接口成功率 `>=99.9%`；控制接口 `p95 <= 1 秒`、`p99 <= 2 秒`（学校云同机测量）；无 5xx、无 SQLite locked/busy、无进程崩溃或自动重放。
- 运行链路：每个合成运行必须有唯一终态，SSE 事件无重复终态、无跨运行事件、可从 `Last-Event-ID` 重放；跨会话泄漏、重复副作用、丢失审计记录均为零容忍。
- 30 分钟保活后再次执行登录、检索、提交和取消；内存持续增长、文件描述符耗尽或任务永久卡在 queued/running 均不通过。记录 CPU、内存、活动执行槽、错误码、首事件和总耗时。

### 5.2 真实模型小流量烟囱（有授权才执行）

- 只使用已配置且明确授权的线路；先单用户、单任务，再最多两个并发任务，保留供应商返回的真实用量和错误类型。
- 不用这组小样本推导生产吞吐、费用优势或客户业务正确率；线路缺失、余额不足或限流时记录为外部输入缺失，不能换用其他模型假装通过。

## 6. 试用交付包和签署条件

交付前必须生成：

1. 学校云冻结提交哈希、白名单发行包和 `manifest.json`（含 SHA-256）；不含 `.env`、数据库、附件、凭据和模型权重。
2. 功能烟囱报告、并发/稳定性报告、浏览器截图或录屏索引、已知限制清单、回滚步骤和服务配置摘要。
3. 一份“可试用/不可承诺”说明：默认只读合成能力、模型可用性、HippoRAG 回退、图片语义质量、OpenClaw 兼容状态和客户 MCP 接入条件逐项列明。
4. 腾讯云入口已获用户条件批准：学校云先完成验收及回滚记录，再只读同步冻结源码和静态成品到独立 release 目录及独立端口。记录旧入口，不覆盖旧服务或复制学校云私有数据库。部署后只做哈希与行为一致性检查，不把腾讯云作为验收环境；失败关闭新入口，不在腾讯云修复分叉。

以下任一项未满足，只能称为“内部预览”而不是“华微可试用版”：功能主链路失败、跨会话/权限泄漏、未知工具可执行、关键压测指标不达标、无法回滚、发行包不完整，或学校云与候选包哈希无法对应。

## 7. 仍需华微或用户提供的外部输入

- 试用入口允许的用户/管理员名单和网络范围；
- OpenClaw 版本、实际入口（Web、OpenAI 兼容或 Gateway WebSocket）及脱敏请求/响应样例（仅做后续适配，不阻塞独立试用）；
- 至少三类脱敏试用任务：业务问答、大数据查询、权限限制，并给出标准答案或判定规则；
- 如需 MCP 联调：地址、传输协议、认证方式、只读工具白名单、字段/金额边界和撤销联系人；
- 允许使用的模型线路及是否允许产生付费调用；1007/1017 和生图线路必须有可验证配置。

在这些输入到达前，可以先交付公开/合成演示和容量报告，但不能把结果写成华微真实业务验收或 OpenClaw 替换完成。
