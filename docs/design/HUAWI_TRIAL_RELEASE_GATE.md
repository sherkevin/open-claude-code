# 华微世纪试用版发布门禁（学校云）

状态：`t13_passed_staging_not_release`（2026-11-13）。OC-T13 第二轮独立只读审核已完成，C1/C2/C3/C4 全部 **PASS**，第一轮 F-B1/F-B2 已关闭。当前 `v4-bound` 只是完整性可核对、审计证据已绑定的 staging 候选，仍明确保持 `release_ready=false`、`publishable=false`、`product_runtime_verified=false`。**这是 T13 执行证据与候选完整性通过，不是产品发布通过，也不是客户验收。**这是面向华微世纪的受控试用版，不是 OpenClaw 全功能替换，也不是生产承诺。

## 试用版目标

让华微在不改造现有 OpenClaw、业务系统和客户数据的前提下，试用知行工作台已经验证的功能子集。首批候选集合是登录、预置助手、基础聊天与取消、会话隔离、公开示例知识库检索、证据链接和文档/图片查看；Excel 导出通过专项验收后可加入。候选不等于已开放，每个启用项必须有本次冻结版本的证据。

试用版通过独立入口或独立租户提供；OpenClaw 原入口保持不变，失败时直接回到原入口。试用版不宣称已替换 OpenClaw 的渠道、Gateway、插件、MCP 或 Agent 执行层。

## 必须通过的学校云门禁

1. **功能烟囱**：本次发布清单中启用的能力全部通过。登录、预置助手、对话发送/回车、停止与恢复、会话隔离、基础模型线路、知识库检索、引用链接、文档/图片查看、撤权和审计构成最小闭环；Excel、图谱预览、上传等按实际加入的范围逐项验收。自动路由、Tab、工作流、子任务、客户 MCP 和生图未验收时不阻塞此版，但须在服务端路由、工具注册和执行时默认拒绝，客户端显示与能力清单一致，不能仅隐藏按钮。
2. **稳定性**：健康检查、鉴权、数据库完整性、SSE/普通请求、取消、重复请求、服务端错误和前端关键路径无未解释失败。
3. **并发压测**：只用合成数据和已授权线路，至少覆盖 1、5、10、25 并发；分开测普通聊天、SSE、知识检索、附件上传和取消。记录吞吐、首字节延迟、完成延迟、错误率、超时率、取消成功率、数据库锁等待、内存和文件句柄。
4. **安全边界**：默认拒绝、最小权限、高风险转人工，租户/用户/文件/知识库隔离，日志脱敏；压测不得使用真实客户数据或凭据。
5. **交付记录**：冻结学校云源码，记录 Git 提交及未提交状态，生成逐文件摘要和暂存包 SHA-256 manifest；绑定启用集合、固定 Harness/Node/依赖、许可、测试报告和回滚步骤。在干净解包目录重跑启动、真实 Harness 加合成模型握手及试用门禁，不能用旧版 FINAL 标记或复用私有运行目录证明新包通过。

## 试用版明确不包含

- OpenClaw Gateway、WebSocket、所有渠道、插件和客户本地 MCP 的完整兼容。
- 真实客户生产数据、客户凭据、客户内网跨网联调和正式业务正确率承诺。
- 未授权付费模型、未经核验的 1007/1017 线路和真实供应商账单节省结论。
- 将当前学校云脏工作树直接同步腾讯云，或直接覆盖腾讯云现有服务。

## 腾讯云发布方式

2026-11-12 用户已明确批准：学校云先测好后，把通过验收的部分功能发布为腾讯云试用入口，无须为同一范围重复请求批准。此授权不包括绕过验收、覆盖旧服务或复制客户数据。使用学校云冻结包，在腾讯云独立目录和独立端口安装；先记录旧入口和回滚方式，核对源码、静态资源及启用集合摘要，再做发布后健康和功能一致性检查。腾讯云检查仅确认部署一致，不替代学校云开发、质量和容量验收。失败时关闭新入口，保留旧版本；学校云始终是唯一源。

### 判定说明

1. **不能把试用烟囱 21/21 当作功能烟囱整体发布通过。** 第二轮独立审核已对 T13 的 C1 执行范围判 PASS；但冻结包安装、启用集合复验和完整试用范围仍未验收。
2. **不能把 1524 项后端通过当作稳定性整体通过。** 17 个 skip 已逐项解释，但其中 13 个真实 Harness runtime 和 4 个 `torch` 缺口仍未关闭；纯产品进程内存基线也未验收。
3. **不能把通过的默认四槽 410 请求矩阵、35,841 请求的 600 秒控制面和 100,766 请求的 1800 秒 soak 当作真实生产容量。** 三项使用默认四槽、合成资料和单进程回环；真实供应商限流和网络延迟未测。100,766 是 1800 秒 soak 总请求，执行层另有 4,259 请求，不能与 600 秒控制面的 35,841 混用。
4. **不能把历史 v3 当作当前发布候选。** v3 源码树摘要为 `871060968c542a0b267c04e29374e7e07343d4eabaec4327dca69a286bc7eb0d`，是 2026-11-12 的历史 staging 快照。返修 1 已建立新的当前源码绑定候选，但其摘要、manifest 和验收绑定以本文“当前候选暂存包”一节为准。
5. **不能把 OC-T15/T16/T17 的 PASS 当作对应需求完成。** 三项分别是路径规范化修复、测试合同修复和测试环境隔离，不是产品能力验收。
