# ADR：新文档实时摄取、RAG 与多模态知识图谱

日期：2026-11-07
项目：知行工作台
状态：已决定，待实现

## 决策

文档上传后由服务端自动创建持久化摄取任务。任务分为快速可用和增强处理两个阶段：

1. 上传事务只负责保存不可变文件版本、校验权限和写入摄取任务；接口返回 `processing`，不等待完整建图。
2. 后台摄取工作线程先完成文本解析、光学字符识别、结构化分块、关键词索引和文本向量，完成后把版本标记为 `rag_ready`。
3. 后台继续处理表格、图片、图形、视觉描述、实体、关系和主张，全部派生对象完成并通过来源校验后标记为 `graph_ready` 或 `multimodal_ready`。
4. 任何实体、关系或主张都必须绑定文档版本、页码/段落/图片区域、提取模型版本和置信度。模型只能提出候选，服务端校验后才写入图谱。
5. 当前运行中的会话继续使用进入运行快照时固定的文档版本；新运行自动看到新版本。失败重试不会覆盖上一个可用版本。

## 模型分层

| 阶段 | 默认模型或方法 | 部署位置 | 说明 |
| --- | --- | --- | --- |
| 原生文本与版面解析 | PDFium、DOCX/XLSX 解析器；复杂扫描页使用 PaddleOCR-VL-1.6 | 学校云 GPU | PaddleOCR-VL-1.6 是约 0.9B 的文档视觉模型，适合中文、表格、公式、图形和版面解析。普通文本 PDF 不经过视觉模型。 |
| 文本与 OCR 向量 | `BAAI/bge-m3` | 学校云 GPU | 生成密集向量，同时保留稀疏/词法能力；中文和多语言文档统一使用。旧 `bge-small-zh-v1.5` 作为低资源回退。 |
| 检索重排 | `BAAI/bge-reranker-v2-m3` | 学校云 GPU | 只对少量候选重排，控制延迟；未安装时使用混合排序。 |
| 本地轻量视觉抽取 | `Qwen/Qwen2.5-VL-3B-Instruct`，四比特量化 | 学校云 GPU | 处理图片区域、简单图形和结构化描述，输出受 JSON Schema 约束的候选实体、关系和证据指针。 |
| 远程高质量抽取与复核 | TokenHub 的 DeepSeek V4.1 Flash | 腾讯云线路 | 处理复杂图表、长文本关系、跨文档实体合并和最终图谱复核。大模型权重不部署在学校云。是否允许发送企业内容由知识库级别的模型出境开关控制。 |

公开 TokenHub 文档当前列出 `deepseek-v4.1-flash` 和
`deepseek-v4.1-flash-1017`；用户提到的 `1007` 作为私有线路候选保留，最终以受控模型目录中实际可调用的上游型号为准，不把不存在的型号写死在代码中。

视觉页面检索暂不把 ColPali/ColQwen 作为默认路径。它们适合页面级多向量检索，但公开训练说明以英文文档为主，且多向量索引会增加工程复杂度。第一版使用 PaddleOCR-VL 和本地三十亿参数视觉模型生成的结构化内容，再配合 BGE-M3；中文工业样本验证通过后再加入视觉检索 tier。

## GPU 调度

- RTX 2080 Ti：OCR、版面解析、文本向量和重排任务。
- 空闲 RTX 3090：本地三十亿参数视觉模型的图谱候选抽取与图片理解。
- 工作线程启动时读取显卡空闲显存，避免占用已经被其他服务使用的显卡；不能假定所有显卡长期可用。
- 远程 DeepSeek 调用设置超时、重试次数、单文档页数和费用上限，失败时保留本地 `rag_ready` 结果并标记图谱阶段失败。
- 学校云禁止部署和缓存大模型权重；大模型调用只经过服务端受控的腾讯接口适配器，密钥只存在服务端私有配置中。

## 持久化状态

增加文档版本级摄取任务和阶段事件，至少包含：`queued`、`parsing`、`ocr`、`embedding`、`rag_ready`、`graph_extracting`、`graph_ready`、`multimodal_ready`、`needs_model`、`needs_ocr`、`failed`。

任务需要租约、尝试次数、错误原因、模型标识、输入版本摘要和更新时间。服务重启时回收过期租约并继续任务，不能依靠进程内存中的队列保证可靠性。

## 验收标准

1. 上传接口在索引未完成时返回，并可通过事件或查询看到阶段进度。
2. 文本 RAG 先达到 `rag_ready`，图谱和视觉阶段随后自动完成。
3. 重启、重复投递和失败重试不会生成重复节点、边或向量。
4. 每条图谱边都能回到具体文档版本和页面/图片区域；撤销权限后检索、图谱和来源读取同时失效。
5. 使用同一组中文工业文档比较本地模型与 DeepSeek 路由，记录解析正确率、实体关系准确率、来源覆盖率、首个可检索时间、完整建图时间、显存和费用。
