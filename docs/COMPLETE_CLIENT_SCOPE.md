# 华微完整 Agent 客户端：本轮交付约定

> 历史范围记录（0.2）。其中跨会话共享记忆语义已由0.4.2的会话独立记忆取代；当前行为和验收以 [接口契约](API_CONTRACT.md)、[工作台指引](WORKSPACE_GUIDE.md) 和 [本版验证](DELIVERY_VERIFICATION.md) 为准。

2026-11-05，根据用户最新澄清。客户仅提供内部读取数据的 MCP；无需预先具备 Harness，也无需自行实现模型、会话、上下文或记忆管理。

## 客户实际使用流程

1. 管理员登录我们的工作台，粘贴 MCP 地址或导入已有 JSON 配置，认证信息在服务端加密保存。
2. 由执行服务器测试连接并发现工具。管理员选择允许使用的工具和必要审批方式，将其绑定到业务助手。
3. 员工选择助手并开始工作。客户端显示流式回答、工具过程、附件和结果；模型调用与执行进程由服务端管理。
4. 同一对话持续使用原生执行会话，断线可重新打开；空闲回收后恢复原会话，不把每条消息当成全新运行时。
5. 同一用户、同一助手的长期记忆可在新对话中继续使用。用户在客户端查看、编辑或清除这些记忆；不同用户、不同助手各自隔离。
6. 对话提供原生上下文状态与压缩操作。压缩使用执行运行时本身的能力，保留真实事件和验证依据，不新增独立摘要服务。

所有模型调用、用量记录、上下文和记忆文件均由我们提供的服务负责。客户的 MCP 继续负责它自身的数据权限；配置共享服务账号不等同于自动继承员工在业务系统中的个人权限。

## 本轮实现验收

| 需求 | 必须观察到的实际行为 |
| --- | --- |
| 简洁配置 MCP | 浏览器导入配置、脱敏预览、保存、测试、绑定助手，随后真实模型使用该连接；用户不编辑执行运行时配置 |
| 完整交互 | 流式回答、工具状态、附件预览、持续对话与重新打开均使用真实后端；保持已有审批、取消和权限能力 |
| 跨会话长期记忆 | 用户保存合成事实后，新建同助手对话能够读取；另一个用户或助手不能读取该记忆 |
| 记忆管理 | 页面显示实际存储内容，支持受版本保护的修改和清除；不把已存在聊天中的事实标成已被遗忘 |
| 原生上下文压缩 | 使用安装版本支持的原生入口，记录真实压缩事件，再继续对话验证必要事实保留；若供应商暂时不支持，不以文字回复冒充压缩 |
| 上下文信息准确 | 展示已观测的用量、压缩状态和事件；未知的窗口容量/占用率不编造百分比 |
| 隔离 | 对话文件、原生会话配置与记忆授权分别检查；记忆共享范围不能让模型读取其他用户或助手的资料 |
| 部署交付 | client/server 独立包、启动配置和运维文档；腾讯云部署及最终源码/归档校验一致 |

真实客户 MCP 尚未提供，本轮先用明确标注合成数据的实际 HTTP MCP 验证上述产品能力。真实业务答案正确率和性能收益仍需客户样本与原方案基线。

## 与前一版的关系

0.1.0 的客户端、服务端、持续会话与 MCP 基础已真实验收。本轮补齐跨对话记忆管理和可操作的原生上下文体验，并简化 MCP 配置。已发布归档保持不变，验证完成后发行新版本。

曾按“对接客户 OpenAI Harness”理解准备的接口方案已被用户最新澄清替代，不作为本轮产品依赖。长期记忆继续使用原生文件机制，不叠加另一套记忆框架或自建摘要器。
