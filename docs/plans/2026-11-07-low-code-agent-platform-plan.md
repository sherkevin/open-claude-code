# 低代码智能体平台阶段计划（2026-11-07）

## 1. 产品判断

“低代码开发平台”不是把现有八层再加成第九层，而是在八层之上的**组合与编排平面**：用户管理原子能力，按业务组合成助手；助手再在会话中调用工作流、工作方法、知识库、模型上下文协议连接和记忆。每个运行步骤仍必须回到原有身份、权限、安全、路由、可观测性和治理约束。

一期对象关系固定为：

```text
助手（业务级 Agent）
├── 工作流（可执行有向图）
│   ├── Agent 节点（受控任务执行）
│   ├── Skill 节点（工作方法）
│   ├── MCP 节点（业务工具）
│   ├── 知识检索节点
│   ├── 条件/人工审批节点
│   └── 输出/产物节点
├── Skills（文本工作方法）
├── 知识库与 RAG
├── MCP 连接与工具授权
├── 记忆范围
├── 模型和路由策略
└── 权限、安全与审批策略
```

## 2. 一次只推进一个优先级

### 优先级 4A：工作流领域契约与本地合成回放

- 建立 Workflow、WorkflowVersion、WorkflowNode、WorkflowEdge 和 WorkflowRun 的版本化契约。
- 节点类型先限制为 `agent`、`skill`、`knowledge_search`、`mcp_read`、`condition`、`approval`、`artifact`；写入和外部副作用默认拒绝。
- 保存草稿和已发布版本；运行时固定版本哈希、助手权限快照和模型选择，不允许活动运行读取未发布修改。
- 本地合成回放只验证拓扑、输入输出边界、节点超时、循环/深度限制、取消和失败隔离，不调用真实模型、客户数据或生产工具。
- 通过条件：同一版本可重放；非法图、环、孤立节点、超长输入和越权工具被拒绝；父运行取消不会重放副作用。

### 优先级 4B：客户可用的可视化构建器

- 在助手详情中增加“工作流”区域和独立编辑页面：节点面板、画布、连线、配置抽屉、版本/发布、测试运行和错误定位。
- 画布只显示安全的执行状态、来源、审批和结构化输出，不显示私有提示词、凭据或逐字思维链。
- 通过条件：用户可以从预设模板复制、修改、校验、发布并回滚；撤销工具/知识权限后，运行前和节点执行前都失败关闭。

当前进展：`client/src/WorkflowPage.tsx` 已提供本地合成画布、节点面板、连线、版本操作和合成测试入口；助手运行时绑定、真实节点执行、取消/重连和客户模板仍未完成。

### 优先级 4C：合成客户模板

- 提供“财务申请”和“财务报销”两个合成模板，包含表单填报 Skill、知识检索、条件分支、人工审批和 Excel 产物节点。
- 模板数据全部标记 `synthetic=true`，金额、审批角色和字段均为演示口径；模板不自动绑定真实客户资源。
- 通过条件：模板可在无真实模型条件下生成计划、展示审批点和导出结构化 Excel；真实财务系统连接仍保持待授权。

当前进展：服务端已提供“财务申请”和“财务报销”合成模板目录及复制为工作流草稿的接口，客户端能力池可以直接复制模板；合成运行已完成声明字段的必填/类型校验，并返回带 `synthetic=true` 的结构化 Excel 预览（不写入真实文件）。现在可选绑定到同一助手的用户会话，并记录版本、会话和最小权限快照；真实助手运行时、正式产物执行和模板依赖管理仍待补齐。

### 优先级 4D：模型辅助构建（后续）

- 仅在人工构建器和版本闸门稳定后，提供“根据自然语言生成草稿工作流”的建议模式。
- 模型只能生成未发布草稿；必须经过节点校验、权限审查、人工确认和本地评测，不能直接发布或执行。

## 3. 八层映射

| 组合能力 | 依赖的八层约束 |
|---|---|
| Agent/Skill/知识/MCP 节点 | 身份提示、知识版本、工具协议、权限、护栏 |
| 条件与审批节点 | 权限、安全、高风险双人审批和审计 |
| 模型节点与自动路由 | 模型授权、预算、路由证据、Tab/补全边界 |
| 工作流运行图与进度 | 子任务隔离、事件流、来源、取消、重连 |
| 草稿、发布、回滚 | 评测闸门、版本哈希、客户基线和交付记录 |
| Excel/图片产物 | 产物权限、公式注入防护、图片模型默认拒绝 |

## 4. 当前不宣称完成的事项

- 没有把现有助手设置页当作低代码工作流编辑器。
- 没有把本地合成 Sub-agent 当作真实客户 Agent 调度器。
- 没有把财务示例当作华微世纪或其客户的真实财务流程。
- 没有在缺少精确模型授权、客户工具和真实样例时调用外部模型或发布工作流。
