# Better AI 工业 Agent 八层架构审计与执行计划

**日期：** 2026-11-07（Asia/Shanghai）
**项目：** open-claude-code（知行工作台）
**审计范围：** 本地源码、自动化测试、现有设计与证据文档；不连接生产、真实客户数据、凭据或未授权付费模型。
**结论：** 八层已经形成一条可运行的本地安全骨架，但只有部分层达到可交付证据。当前最重要的事实不是再堆页面，而是把每一层的“可验证边界、真实证据和回滚条件”固定下来。

## 1. 八层定义

本审计把用户描述的故事映射为八层。第八层是让系统在上线后持续保持正确，而不是一次性做完就失控。

1. **品牌与系统提示层：** 公开身份、公司语气、任务边界、来源引用规则。
2. **知识库与 RAG 层：** 文档版本、分块、BM25、向量检索、上下文组装和引用。
3. **MCP Agent 工具层：** 连接、工具发现、调用、业务来源和执行结果。
4. **身份与权限层：** 用户、角色、助手、知识库、连接和工具的服务端授权。
5. **安全护栏层：** 提示词注入、敏感信息、路径、网络、输出和审批前后复核。
6. **缓存与模型路由层：** 上下文缓存、模型推荐、成本与延迟边界、故障回退。
7. **可观测性与评测层：** 运行事件、用量、时延、来源、审批审计和固定基准。
8. **持续治理与交付层：** 变更评测闸门、版本快照、回滚、客户对标和发布证据。

## 3. 重点事实与边界

### 已经能给人使用的部分

- 知识库页面可以创建资料集合、上传文件、查看解析状态、切换混合 RAG/BM25/本地向量，并复制有长度上限的检索上下文。
- 文本知识检索结果带文档、版本、哈希、页码或段落定位；知识库绑定和来源打开会执行权限检查。
- 基础 Agent 可以通过 MCP 工具读取授权知识或网页，并在工具结果中登记真实来源；写入或外部 MCP 工具仍按审批策略处理。
- 本地合成消融明确比较“知行工作台（增强模块）”与“最简单 Agent（客户现有助手的消融替身）”，没有伪造真实客户或模型速度数字。

### 不能写成已完成的部分

- 图片缩略图、页面预览和 OCR 状态不是视觉向量、视觉实体识别或多模态图谱完成证据。
- `local-lexical-v1` 是词法向量回退，不是语义多模态模型；只有配置并验证本地模型后才能声称语义向量检索。
- 合成消融的 Token 是固定文本估算；增强方案按“压缩后输入 + 输出”计费，本地压缩过程不计入，基线保留同任务原始上下文以形成可解释的消融差异。模型响应速度、真实费用、上下文质量和客户助手指标仍保持 `not_measured`。
- 当前没有证据证明已路由到精确的 `deepseek-v4.1-flash-1007`；授权目录记录的是 `deepseek-v4.1-flash-1017`，禁止把两者混写。
- 当前已有有界 Excel 生成与下载流程，已覆盖本地结构化导出、公式文本转义和用户权限；但还没有经授权的 TokenHub 生图线路，不能宣称“自动生成 Excel 和图片”已经全部交付。

## 4. 可执行阶段计划

每阶段只进入一个优先级；完成后必须运行对应测试、更新证据文档，再决定是否进入下一阶段。任何需要生产、真实客户、凭据或付费模型的步骤都停在“待批准”。

### 阶段 A：把人可用的 RAG/BM25 做成可验收闭环（本地、不触碰生产）

1. 固定一组脱敏工业样例（文本、表格、带图片的 PDF），为每个问题写标准答案和期望来源。
2. 增加检索响应中的索引状态、解析方法、分数组成和 `not_measured` 说明；保持 BM25、向量和混合模式可切换。
3. 为上传、失败重试、版本快照和撤权补充异步状态契约；不改变现有同步基础，先保证重复重试不产生重复索引。
4. 验收命令：`PYTHONPATH="$PWD:/tmp/open-claude-pylib" pytest -q server/tests/test_knowledge_evidence.py`，并运行客户端测试与类型检查。
5. 通过条件：固定样例的召回、来源、权限和上下文长度断言全部通过；视觉模型缺失时明确显示待处理。

### 阶段 B：多模态图谱和可视化（本地模型或用户批准后）

1. 先完成页面/图片区域、表格单元格、实体和主张的来源模型；每个节点都绑定文档版本和权限版本。
2. 只有拿到批准的本地视觉嵌入/视觉语言模型及脱敏图像后，才实现视觉向量和实体抽取；否则保留 `needs_model`。
3. 客户端增加证据区域定位、图谱节点筛选/展开、图片和表格预览，禁止把缩略图当语义实体。
4. 通过条件：权限撤销立即隐藏节点和来源；同一版本可重放；图谱关系能回到具体页、段、单元格或图片区域。

### 阶段 C：业务工具和权限安全（合成先行）

1. 用回环 MCP 建立只读、写入、高风险和未知工具矩阵；每个工具记录风险、数据范围、金额边界和审批策略。
2. 扩大提示词注入与输出脱敏攻击集，覆盖附件、网页、工具结果、编码和多轮组合；将失败样例存为私有证据，不写凭据。
3. 验收父子任务取消、审批过期、策略撤销、服务恢复和双人投票；生产角色矩阵与真实 MCP 仍待用户提供。

### 阶段 D：路由、缓存和可观测性（仅已有授权模型）

1. 先验证当前授权模型目录，缺失精确 1007 映射时继续安全失败，不调用未授权线路。
2. 采集真实模型请求的输入/输出 Token、首字节、总时延、错误、费用来源和路由理由；不把估算写成实测。
3. 评估是否需要应用级回答缓存：仅允许不含私有数据、权限和外部副作用的明确幂等请求；默认关闭跨用户缓存。
4. 路由变更必须保留候选、目标、策略版本和报告哈希，活动运行不能切换模型。

### 阶段 E：交付物与持续评测

1. 本地有界 `xlsx` 导出已完成首轮验收：固定列、编码、公式文本转义、下载权限和大小边界；后续仍需按业务确认补字段与模板，CSV 可沿用现有文件下载路径。
2. TokenHub 生图需用户提供已授权的模型标识、端点、额度和安全边界；未提供前只保留图片上传、预览和 `needs_model` 状态。
3. 让每次系统提示词、模型路由、解析器、检索权重、审批策略变更先跑固定基准；正确性、来源覆盖、权限、安全和成本任一回归失败就禁止发布。
4. 保存原始 JSON、图表和差异说明；真实客户对标只接受脱敏样例、权限确认、标准答案和批准的调用端点。

## 5. 当前需要的外部输入

- 精确 `deepseek-v4.1-flash-1007` 的 TokenHub 目录映射、授权范围和额度（当前仅有 1017 证据）。
- 华微世纪及客户的脱敏业务样例、标准答案、角色/工具/金额权限矩阵，以及客户现有助手的同任务运行方式。
- 图片/扫描件样例和获批的本地视觉嵌入或视觉语言模型；否则多模态图谱只能展示资产和状态。
- Excel 导出字段/格式和 TokenHub 生图模型授权；外部发布、生产重启和线上构建仍需单独批准。
