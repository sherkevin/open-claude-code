## 2. 目标和原则保持不变

我方是开物平台管理者，华微已有内网 Windows MCP。交付一个 Windows 桥接器，由客户 Windows 主动连接我方中转；我方提供受保护的公网 MCP 地址和标准 JSON，导入开物后可在对话中查询客户授权开放的数据。

本期采用企业统一入口与客户本机固定业务读取身份。客户内部 Bearer、HMAC key、channel、userid 只在本机填写；开物 JSON 使用我方独立签发的企业集成凭据 K。

优先复用官方原版 frps/frpc 和本仓库已有能力。本期一个 Windows 连接器使用一个专属 frps 实例，配合 visitor 与 STCP；不开发 FRP 核心协议或鉴权插件，不把员工 OAuth 映射加入前置条件。必要开发集中在配置、打包、生命周期及 MCP 业务适配。

所有工程、安装包、缓存、日志、临时文件都放在 /media/data3/dengkw/。根分区没有余量；不要转写 /tmp、/home 或根分区，不擅自修改 HOME/CODEX_HOME 等全局设置。
