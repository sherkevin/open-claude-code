# 开物企业连接器：交付与运维演进计划

## 产品目标与不可变约束

让不懂技术的业务人员完成安装、企业绑定、业务连接和必要的协助授权；开物工程人员在授权范围内自行完成诊断、修复和端到端业务验收。

华微内网不接受公网主动入站连接：连接器主动建立 HTTPS/WSS 出站通道，主动轮询云端协助队列、领取本设备的授权任务、执行并回传结果。云端保存任务及其状态；禁止以开物主动连接客户内网端口替代此方案。持续在线不等于持续授予远程操作权限。客户撤销授权、设备撤销或隔离、会话过期时停止下发任务。

## 当前基线与本轮改动

- 基线 main: cc0c1aa。远程命令、回传、保活及 MCP 认证兼容等既有成果已在主分支，不重复合并等价提交；其它工作区未提交的改动不纳入。
- 新增仅控制面管理员可调用的只读接口 GET /api/kaiwu/v1/connectors/{connector_id}/mcp-export-status，检查企业导出许可、设备状态、中继状态、HTTPS 配置及最近一次导出拒绝原因。
- 导出失败审计在业务事务回滚后记录；只记录已认证的企业与设备、固定错误码、HTTP 状态、时间和追踪编号，不保存业务配置、密钥、请求正文或未验证来源标识。最近一次历史拒绝不代表当前一定失败；本接口不是全链路验收或授权接口。
- 服务端协助授权以创建时间为起点，24 小时绝对上限与 30 分钟滑动有效期取较早者；客户端轮询不再无限延长授权。24 小时为本轮沿用客户端既有上限的产品默认值，不是客户业务连接器的在线时限。
- 不改变现有签名、认证、租户隔离、设备撤销、操作人归属和任务领取机制，不自动授权任何企业。

## 开发顺序与验收门槛

| 优先级 | 工作 | 验收条件 |
| --- | --- | --- |
| P0 | 华微实际业务接入 | 授权管理员核查对应企业及设备的导出限制；经企业批准后按既有流程配置；验证真实只读 ERP 调用成功，并留存脱敏证据 |
| P0 | 诊断中心 | 管理员可按授权企业、设备、时间及追踪编号定位故障；面向客户只展示简明状态和协助入口；不记录原始凭据 |
| P0 | 协助授权及审计 | 分离诊断与系统维护权限；最小权限服务账户；明确告知和授权；停止协助、撤销、超时后不能领取新任务；审计访问隔离、脱敏和留存策略 |
| P0 | 任务生命周期 | 云端持久化排队；客户主动领取并回传；设备身份与企业绑定；限定有效期、幂等回传、取消与恢复；验证重复轮询、断网、重启、跨租户拒绝 |
| P0 | 客户端交互 | 普通用户无需理解 MCP/JSON；技术配置移入管理或高级界面；故障时提供一键协助与本次授权可见状态 |
| P0 | 安装与升级 | 联合试用验证安装、覆盖升级、配置保留、失败回滚及干净卸载；保持终端防护；组织代码签名作为后续对外发行能力完善 |
| P1 | 多租户运维工作台 | 在授权范围内查看设备、版本、状态、诊断及审计；敏感配置与运维输出受访问策略约束 |
| P1 | 稳定性与兼容 | Windows 11、Server 2019 实机及 Linux 兼容计划；24/72 小时稳定性、断网恢复、重启、并发、队列积压与越权测试 |
