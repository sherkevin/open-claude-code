# 开物连接器安装后快速检查

**1.3.8 待实测草稿 · 2026年11月19日**

> 内部核对说明：本稿已按当前页面文字整理，但 Windows 安装、自动启动、连接测试、示例启停和开物实际对话仍需完成实测。验收通过并补齐真实截图后，才能并入客户正式说明。本稿不替代已交付的 1.3.6 说明。

连接器自带一个测试 MCP 服务，用固定的示例数据检查这台服务器与开物之间的连接。**示例订单和库存都是测试数据，不是华微世纪的真实业务数据。** 首次检查无需填写数据库密码或真实 MCP 地址。

操作顺序是：**安装并打开页面 → 绑定企业 → 运行连接测试 → 等技术支持完成平台接入后，在开物对话中查询示例数据。**

## 一 安装后找到测试区域

1. 在准备接入开物的 Windows 服务器上运行安装包，按照安装向导完成安装。
2. 安装完成后，在这台服务器上打开 [连接器配置页面](http://127.0.0.1:17872/)。
3. 找到页面靠上方的 **“内置测试服务（示例数据）”** 区域。测试服务默认随连接器自动启动，无需另装程序或手动启动。
4. 查看这个区域右上角的状态。如果未显示正常运行，或出现错误提示，请保留截图并联系开物技术支持。

内置测试服务有自己的区域和按钮，**无需在下方“当前配置对象”列表中选择，也无需填写“配置当前服务器的 MCP 服务”表单**。

配置页面要在安装连接器的服务器上打开。其他员工日常使用开物公网网页即可。

## 二 完成企业绑定

如果这台服务器已经显示绑定成功，可以直接进入第三节。

首次绑定按下面操作：

1. 向下找到并展开 **“高级选项与诊断详情”**。
2. 在其中找到 **“企业绑定”**。
3. 从随安装包发送的正式《开物内网连接器安装与使用说明》第四节，复制本次有效的 **一次性接入码**，粘贴到输入框，然后点击 **“绑定企业”**。
4. 看到绑定成功后，回到上方 **“内置测试服务（示例数据）”** 区域。

接入码只在首次绑定时使用。如果提示过期、已使用或绑定失败，请在华微世纪飞书群联系开物技术支持。已经绑定成功的服务器不需要再次输入接入码。

## 三 点击“运行连接测试”

在 **“内置测试服务（示例数据）”** 区域直接点击 **“运行连接测试”**，等待页面显示结果。无需先选择业务服务。

页面会分四项显示检查结果：

| 页面上的项目 | 检查什么 | 未通过时怎么办 |
| --- | --- | --- |
| 本机示例 MCP | 服务器上的测试服务是否能正常返回示例数据 | 保留错误提示，请开物技术支持检查安装和本机服务 |
| 企业绑定 | 这台服务器是否已经绑定到本次试用企业 | 按第二节检查绑定状态 |
| 公网隧道 | 这台服务器是否已连接到开物公网服务 | 提供失败提示和发生时间，请技术支持检查连接情况 |
| 开物平台连接 | 开物公网能否经过连接通道，取回这台服务器上的示例结果 | 提供失败项和页面显示的链路追踪编号，请技术支持排查 |

如果出现“跳过”“未执行”或失败提示，说明相应步骤尚未通过。只有本机检查通过，不能作为公网连接成功的依据。

**“运行连接测试”成功，说明测试连接已通过。要在开物对话中查询示例数据，还需由开物技术支持完成测试服务的接入，并告知使用哪个助手。**

高级区域中的地址预览不能直接用于完成这一步。客户无需自行复制预览内容或拼写配置；平台侧接入由开物技术支持完成。

## 四 在开物对话中查询示例数据

收到开物技术支持“测试服务已接入”的确认后：

1. 打开 [开物平台](https://flintw.com/project/kaiwu/)，使用已分配的试用账号登录。
2. 选择技术支持告知的测试助手。
3. 回到连接器页面，在测试服务区域点击 **“复制测试问题”**，再把问题粘贴到开物对话中发送。

页面提供的测试问题是：

> 请用内置测试服务查询订单数和 KAIWU-DEMO-001 的库存。

预期回答应明确说明：**示例订单数为 12，商品 KAIWU-DEMO-001 的示例库存为 128。**

也可以分别提问：

| 可以直接复制的问题 | 预期结果 |
| --- | --- |
| 请调用内置测试服务，检查服务是否在线。 | 返回本次在线检查结果 |
| 请查询内置测试服务的示例订单总数。 | 示例订单总数为 **12** |
| 请查询内置测试服务中商品 KAIWU-DEMO-001 的库存。 | 示例库存为 **128** |

若助手只给出一般说明、表示无法访问，或回答与上述结果不符，请把问题、回答和发生时间发到群里，由技术支持核对实际调用记录。

**这些示例结果只用于检查连接，不能代表贵公司的真实业务数据已经接入。**

## 五 接入贵公司的业务 MCP

示例测试完成后，再由维护贵公司现有 MCP 服务的同事填写业务配置：

1. 在 **“配置当前服务器的 MCP 服务”** 区域，选择 **“＋ 新增 MCP 服务”**。
2. 填写服务名称、已有 MCP 的完整地址，以及该服务要求的访问参数。
3. 点击 **“读取工具列表”**，勾选本次允许开物使用的查询工具。
4. 点击 **“保存并连接”**，按页面提示检查结果。
5. 通知开物技术支持完成业务服务的平台接入，然后在开物中查询一条已知正确结果的业务问题，与原业务系统核对。

内部访问参数由贵公司负责维护 MCP 的同事在服务器本机填写。“保存并连接”会按新配置重新建立连接；已有业务正在使用时，请由维护同事安排操作时间。已有业务配置应保留。

提问时请说明要查询“内置示例数据”还是“贵公司业务数据”，方便确认所用服务。

## 六 测试服务的停用与恢复

不再需要示例数据时，可在顶部测试区域点击 **“停用内置测试服务”**。需要时再使用同一区域的启用按钮恢复。

停用或恢复测试服务，应只影响示例服务；已接入的业务服务应继续运行。**这项行为仍属于 1.3.8 待实测验收内容。**

一种特殊情况是：先停用测试服务，再重启连接器，之后在业务连接运行中重新启用测试。如果页面提示 **“测试通道尚未就绪，请在方便时重新连接”**，请保留当前业务连接，联系开物技术支持安排重新连接。测试按钮不会为此自动中断正在使用的业务通道。

## 七 出现问题时怎样反馈

页面下方有 **“运行日志”** 区域，可以切换 **“连接器日志”** 和 **“开物调用日志”**。请先记录发生问题的时间，再查看对应日志；必要时点击 **“下载脱敏日志”**，把文件发给开物技术支持。

| 看到的情况 | 下一步 |
| --- | --- |
| 本机测试正常，后面的连接步骤失败 | 提供失败项、发生时间和链路追踪编号，请技术支持检查连接通道 |
| 连接测试正常，开物对话仍不能查询示例数据 | 提供所选助手、问题和回答，请技术支持核对测试服务是否已接入该助手 |
| 示例查询正常，真实业务查询失败 | 双方共同检查真实 MCP 的地址、访问参数、服务状态及兼容情况；示例通过不能直接说明问题一定出在客户配置 |
| 恢复测试服务时提示需要重新连接 | 保留正常业务连接，联系技术支持安排处理 |

反馈时提供 **连接器版本、操作步骤、发生时间、错误截图，以及页面显示的链路追踪编号** 即可。截图中如有访问令牌、密钥或敏感业务数据，请先遮挡；不要把内部访问密码发到群里。
