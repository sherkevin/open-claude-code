# Better AI 工业 Agent 产品升级计划

> 历史计划说明（2026-11-11）：下文状态、22/22 统计、授权限制和“当前”均是当时阶段记录，不是现行需求或在线状态。当前唯一需求入口为 [REQUIREMENTS_ALIGNMENT.md](REQUIREMENTS_ALIGNMENT.md) v0.4；其中明确了最简单 Agent 消融、三级风险/四种审批策略、完整八层、产物和工作流范围，以及真实质量验收门槛。已有授权模型与公开资料开发不再一概待批准；生产、共享服务、真实客户数据和未授权线路仍受边界限制。保留本计划用于追溯，不以历史阶段完成代替产品完成。

**日期：** 2026-11-06（Asia/Shanghai）  
**项目：** open-claude-code / 知行工作台  
**状态：** 阶段 0 合成基准最小闭环已完成；产品端到端、真实客户调用和付费模型验收仍需单独批准

## 目标

把知行工作台建设为 Better AI 工业 Agent 的主产品：兼容业务方的 OpenAI-compatible Responses/Chat Completions 接口和标准 MCP，支持用户上传文档后自动扩充知识库与多模态知识图谱，提供可追溯的 RAG 与图谱可视化，自动选择合适模型，支持 Tab 意图补全、四种审批策略、Sub-agent 自动拆分和安全的滚动执行进度，并用固定的合成基准与业务方现有助手进行可重复对标。

## 已确认的产品边界

- **协议：** 模型侧支持 OpenAI-compatible Responses API 和 Chat Completions API；工具侧支持标准 Streamable HTTP MCP，并兼容 OpenAI Responses MCP 配置对象/数组。
- **上传格式：** PDF、DOCX、XLSX、CSV、Markdown、TXT、JSON 和常见图片；首期优先本地解析和本地 OCR，外部视觉模型另行审批。
- **审批策略：** 安全只读自动批准、模型代用户批准、用户明确批准、管理员或双人批准。模型代审不能处理高风险操作，所有策略都必须在服务端复核授权并记录审计。
- **执行展示：** 展示计划、阶段、工具调用、审批、上下文压缩、子任务和结果等安全状态，不展示模型私有逐字推理链。
- **对标方式：** 先用合成助手、合成 MCP、文档、表格、图片和标准答案建立基准，再接入真实样例；未测指标显示待测，不能用宣传数字替代证据。

## 阶段路线

**状态：** 最小闭环完成，产品接入与跨平台对标待后续阶段

- 建立合成基准助手、标准答案、OpenAI-compatible 模型夹具、标准 MCP 夹具和工业文档/表格/图片样本。
- 设计统一的运行指标格式：正确性、来源覆盖率、首字节时间、完成时间、输入/输出 Token、费用、上下文、记忆、多模态解析和图谱引用。

**本轮接手结果（2026-11-06）：**

- 44 个需求编号已完成逐项状态登记；优先级 3 后当前为 22 项已实现、22 项部分实现、0 项设计中、0 项 TODO。MOD-004 已有任务提交时的有界本地自动路由，但成本/延迟实测和真实模型回归仍待完成；BENCH-003 已提供管理员可见的合成柱状图和待测状态；RAG-005 仅完成图片/PDF 本地资产阶段；SUB-001/002、APR-002、APR-004 仅完成本地合成安全闭环，真实模型、Sub-agent 生产调度、真实子会话审批和客户角色仍待验收。详见 [需求审计](verification/REQUIREMENTS_AUDIT_NOTES.md) 第 9、10 节。
- 已记录学校云依赖缺失导致的本机回归阻塞；远端历史 322/53 仅作为远端开发树证据。详见 [回归环境记录](evidence/REGRESSION_RECHECK_2026-11-06.md)。
- 已建立 `fixtures/synthetic-industrial-v1/`、只读回环 MCP、标准答案、固定版本与哈希、清理命令和 JSON 指标报告；离线 4 项任务与 5 项断言通过。当前 runner 不启动产品助手、不调用模型，Token/上下文/视觉和跨平台指标保持 `not_measured`。

### 阶段 1：协议与数据摄取

**状态：** 最小本地能力已落地，产品端到端协议回归待执行

- 完成 OpenAI-compatible Responses/Chat Completions 适配器和错误/用量映射。
- 合成 MCP 服务、工具授权边界和安全来源标记已有只读回环夹具；仍需接入产品端到端协议回归。
- 上传入口已覆盖八类文档/图片中的 DOCX、XLSX 和常见图片，本地解析、OCR 缺失状态、分块、版本、索引和失败重试已有同步基础；统一异步进度和真实 OpenAI-compatible 上游验收待执行。

**验收：** 只使用 synthetic 数据跑端到端任务；任何凭据都不进入客户端、日志或证据报告。

### 阶段 2：RAG 与多模态图谱

**状态：** 最小版本化图谱与可视化已落地，语义多模态能力待执行

- 建立文档、页面、段落、表格、单元格、图片区域、实体、关系和主张的版本化模型。
- 每个检索片段和图谱关系必须保存来源指针、权限版本和解析状态。
- 图谱查询 API、当前版本权限复核和前端 SVG 可视化已有最小闭环；仍需补语义实体/主张、图片区域、增量任务、证据区域交互和完整 RAG 链指标。

**验收：** 上传新版本不改变正在运行任务的快照；删除或撤销绑定后，检索、图谱和来源链接都拒绝访问；失败解析可以重试且不产生重复节点。

### 阶段 3：模型路由与审批控制

**状态：** 有界自动路由、模型代审和高风险双人审批的本地合成最小闭环已落地；真实模型、客户角色和生产默认策略仍待执行

- 任务提交时的有界本地自动路由、回退、活动任务保护和请求级手动覆盖已落地；成本/延迟权衡、持久化报告和真实模型回归仍待补齐。
- 已实现模型代审的默认拒绝、低风险最小权限和审计，以及高风险双人投票的策略快照、拒绝优先、重启/策略变更失效、管理员待审批过滤和本地合成 Sub-agent 审批级联；仍需真实子会话、生产角色矩阵和生产验收。
- 模型代用户批准只允许在管理员配置的低风险范围内运行，默认关闭高风险能力。

**验收：** 路由决策可重放、候选白名单有效、预算有效、切换不会污染既有运行；高风险动作无法由模型单独放行。

### 阶段 4：Sub-agent 与执行体验

**状态：** 优先级 1 本地合成阶段完成；生产与真实模型阶段待执行

- 已实现本地合成有界任务拆分、子任务持久化、独立 workspace/memory 标识、只读能力快照、父事件和取消/恢复生命周期；证据见 [SUBAGENT_LOCAL_PRIORITY1_2026-11-06](evidence/SUBAGENT_LOCAL_PRIORITY1_2026-11-06.md)。
- 仍需实现真实会话/工作区/记忆/预算/工具权限、跨进程审批恢复、产物来源和真实负载，再将计划、子任务、工具、审批、上下文、来源和产物接入统一事件流；本地合成审批级联已完成阶段性验证。
- 完善客户端滚动小字和最近步骤显示，保持安全摘要，不输出私有思维链。

**验收：** 父任务取消级联生效；一个子任务失败不误取消兄弟任务；重启不自动重放外部写操作；子审批无法越权。

## 当前禁止事项

- 不重启或重新部署现有 systemd 服务。
- 不修改 `.runtime/data`、凭据、虚拟环境或生产 `client/dist`。
- 不连接真实客户 MCP、真实模型或付费上游，除非用户明确批准。
- 不把设计状态、合成基准结果或局部测试结果写成生产能力已上线。
