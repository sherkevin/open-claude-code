# Better AI 工业 Agent 产品升级计划

**日期：** 2026-11-06（Asia/Shanghai）  
**项目：** open-claude-code / 知行工作台  
**状态：** 持续执行；生产部署、真实客户调用和付费模型验收仍需单独批准

## 目标

把知行工作台建设为 Better AI 工业 Agent 的主产品：兼容业务方的 OpenAI-compatible Responses/Chat Completions 接口和标准 MCP，支持用户上传文档后自动扩充知识库与多模态知识图谱，提供可追溯的 RAG 与图谱可视化，自动选择合适模型，支持 Tab 意图补全、四种审批策略、Sub-agent 自动拆分和安全的滚动执行进度，并用固定的合成基准与业务方现有助手进行可重复对标。

## 已确认的产品边界

- **协议：** 模型侧支持 OpenAI-compatible Responses API 和 Chat Completions API；工具侧支持标准 Streamable HTTP MCP，并兼容 OpenAI Responses MCP 配置对象/数组。
- **上传格式：** PDF、DOCX、XLSX、CSV、Markdown、TXT、JSON 和常见图片；首期优先本地解析和本地 OCR，外部视觉模型另行审批。
- **审批策略：** 安全只读自动批准、模型代用户批准、用户明确批准、管理员或双人批准。模型代审不能处理高风险操作，所有策略都必须在服务端复核授权并记录审计。
- **执行展示：** 展示计划、阶段、工具调用、审批、上下文压缩、子任务和结果等安全状态，不展示模型私有逐字推理链。
- **对标方式：** 先用合成助手、合成 MCP、文档、表格、图片和标准答案建立基准，再接入真实样例；未测指标显示待测，不能用宣传数字替代证据。

## 阶段路线

### 阶段 0：需求与基准冻结

**状态：** 进行中

- 把新增需求登记到 `docs/REQUIREMENTS_ALIGNMENT.md`，为每项指定状态、验收命令和证据路径。
- 建立合成基准助手、标准答案、OpenAI-compatible 模型夹具、标准 MCP 夹具和工业文档/表格/图片样本。
- 设计统一的运行指标格式：正确性、来源覆盖率、首字节时间、完成时间、输入/输出 Token、费用、上下文、记忆、多模态解析和图谱引用。

**验收：** 固定版本、随机种子、数据哈希、清理策略和报告目录；不连接真实客户服务。

### 阶段 1：协议与数据摄取

**状态：** 待执行

- 完成 OpenAI-compatible Responses/Chat Completions 适配器和错误/用量映射。
- 完成合成 MCP 服务、工具授权、审批策略夹具和安全来源标记。
- 扩充上传入口与任务状态，支持八类文档/图片；本地解析、OCR、分块、版本、索引和失败重试统一进入事件流。

**验收：** 只使用 synthetic 数据跑端到端任务；任何凭据都不进入客户端、日志或证据报告。

### 阶段 2：RAG 与多模态图谱

**状态：** 待执行

- 建立文档、页面、段落、表格、单元格、图片区域、实体、关系和主张的版本化模型。
- 每个检索片段和图谱关系必须保存来源指针、权限版本和解析状态。
- 实现 RAG 检索链 API、图谱查询 API、权限复核和前端可视化。

**验收：** 上传新版本不改变正在运行任务的快照；删除或撤销绑定后，检索、图谱和来源链接都拒绝访问；失败解析可以重试且不产生重复节点。

### 阶段 3：模型路由与审批控制

**状态：** 待执行

- 将当前按钮式模型推荐升级为任务提交时的自动路由，同时保留用户覆盖和活动任务保护。
- 实现四种审批策略及其审计字段、超时、取消、重启失效和 Sub-agent 级联。
- 模型代用户批准只允许在管理员配置的低风险范围内运行，默认关闭高风险能力。

**验收：** 路由决策可重放、候选白名单有效、预算有效、切换不会污染既有运行；高风险动作无法由模型单独放行。

### 阶段 4：Sub-agent 与执行体验

**状态：** 待执行

- 实现服务端有界任务拆分、子任务持久化、独立会话/工作区/记忆/预算/工具权限和取消恢复。
- 将计划、子任务、工具、审批、上下文、来源和产物接入统一事件流。
- 完善客户端滚动小字和最近步骤显示，保持安全摘要，不输出私有思维链。

**验收：** 父任务取消级联生效；一个子任务失败不误取消兄弟任务；重启不自动重放外部写操作；子审批无法越权。

### 阶段 5：对标与交付

**状态：** 待执行

- 用相同任务、数据、工具和预算运行本平台与合成的业务方基准助手。
- 生成 JSON 原始报告和客户端柱状图、折线图或雷达图。
- 接入真实客户样例前，先完成数据脱敏、权限确认、模型成本确认和回滚方案。

**验收：** 每个优势结论都有原始证据；缺失数据明确显示待测；生产部署另行备份、验证并等待批准。

## 当前禁止事项

- 不重启或重新部署现有 systemd 服务。
- 不修改 `.runtime/data`、凭据、虚拟环境或生产 `client/dist`。
- 不连接真实客户 MCP、真实模型或付费上游，除非用户明确批准。
- 不把设计状态、合成基准结果或局部测试结果写成生产能力已上线。
