# 华微公司知识库：分支验收清单（2026-11-13）

## 1. 目的与范围

本清单对应分支 `oc-huawi-company-kb`，用于验收“华微公司知识库”这一分支内的
可复现样例、来源边界、图片证据和人工复核图谱。它不是生产迁移记录，也不代表
腾讯云或共享服务已经更新。所有命令均应在学校云的该分支工作树运行。

原始飞书归档只保留在学校云受控目录 `huawi-source-materials/`，不进入 Git。可
提交的内容是脱敏后的检索文本、有限页预览、清单和图谱复核结果。

## 3. 可复现命令

```bash
# 只在分支工作树执行，不指向共享或生产数据目录
python3 scripts/build_huawi_kb_fixture.py \
  --source huawi-source-materials \
  --output fixtures/huawi-company-kb-v1

TMPDIR=/dev/shm/huawi-tests \
  /media/data3/dengkw/projects/open-claude-code/.venv/bin/python -m pytest -q \
  server/tests/test_knowledge_evidence.py server/tests/test_huawi_company_kb.py

# 2026-11-13：50 passed，1 个既有 Starlette/httpx 弃用警告。
```

将样例导入临时目录时，管理员账号必须已经存在：

```bash
python3 scripts/seed_huawi_company_kb.py \
  --fixture fixtures/huawi-company-kb-v1 \
  --data-dir /media/data3/dengkw/huawi-kb-branch-data \
  --admin-username <已有管理员账号> \
  --include-media
```

该命令不是生产迁移。执行前应确认目标目录是一次性或专用目录，并在验收记录
中保存清单哈希、图谱质量收据和测试结果；不得把管理员密码写入命令历史或文档。

## 4. 尚缺证据与后续门槛

1. 群内图片附件没有可用的原始图片文件，本分支只提交 PPTX 页面预览，不能宣称
   已覆盖所有群图片或完成图片实体识别。
2. 当前视觉索引状态是 `needs_model`，尚未使用已授权视觉向量模型跑召回率、跨页
   多跳检索和图片证据引用测试。
3. 图谱的 90%/10% 指标是验收目标，不是对当前人工种子或全部会议文本自动抽取的
   统计结论；正式验收需提供标注集、抽样规则和独立评审记录。
4. 本文档不授予合并、部署或将知识库绑定到默认助手的权限；这些动作需要单独的
   发布审批和可回滚记录。
