## 可复现命令

从合并后的项目根目录执行，先按 README 配置依赖和私有环境：

```bash
cd client
npm ci
npm test
npm run build
cd ../server
../.venv/bin/python -m pip install '.[test]'
../.venv/bin/python -m pytest -q
cd ..
.venv/bin/python scripts/smoke_api.py --password-file .runtime/admin-password --origin http://127.0.0.1:18081 --report .runtime/api-smoke.json
```

`smoke_api.py` 的资源权限检查遵循当前合同：成员创建默认个人连接必须返回
`201` 并归属该成员；成员显式创建 `scope=team` 必须返回 `403`；成员对其他
成员或管理员的个人连接读取、修改必须返回 `403` 或 `404`。因此，成员创建个人
连接不是验收失败，脚本会在清理阶段删除本次创建的个人连接。

验收助手由管理员显式创建为 `scope=team`，但仍使用
`access.all_members=false` 与成员 `user_ids` 白名单：白名单成员必须可见，未授权
成员必须不可见且不能创建会话。这里的团队范围表示配置由管理员管理，不表示所有
成员自动获得助手访问权。脚本为该助手单独创建并测试一个团队连接；个人连接仍
保留用于跨所有者拒绝检查，避免把私有连接错误地绑定到团队助手。

浏览器验收需要安装 Playwright 及可用的 Chromium。默认不启用付费模型调用：

```bash
npm install --prefix .local/browser playwright
node .local/browser/node_modules/playwright/cli.js install chromium
node scripts/browser_smoke.mjs --base-url http://127.0.0.1:18081 --password-file .runtime/admin-password
```

API 真实模型验收使用 `--real-model`；浏览器真实模型验收使用 `REAL_MODEL=true`。这两种方式会调用配置的模型服务并产生用量。验收报告与轨迹可能包含任务内容，应保存在受控目录，不加入发行包。

会话生命周期脚本和操作步骤随部署资料包提供：

```bash
.venv/bin/python scripts/lifecycle_smoke.py plan
```

实际四轮验收及隔离服务重启步骤见 [会话生命周期说明](SESSION_LIFECYCLE.md)。该脚本在 Linux 执行节点观察真实进程和 SDK 会话身份；它不会自行重启服务。本次所有阶段均已实际通过，专用验收资源已清理，短时验收用的空闲回收间隔已恢复为 600 秒。

逐任务比较脚本 `scripts/benchmark.py` 与示例任务 `docs/acceptance-tasks.example.json` 一同交付。示例只用于验证流程；任务执行成功不等于业务答案正确。原方案与新方案应使用相同模型、任务、数据和工具，再分别审核质量、耗时及实际成本。
