# 0.4.1 助手详情配置修复验证

更新日期：2026-11-05。

Release version: 0.4.1
Release readiness: FINAL

问题：工作台点击助手后只打开会话列表，知识库、数据连接、Skills 和网页搜索只能从另一个管理窗口配置，未满足用户在助手详情直接配置的操作方式。

本次修复：工作台中的助手进入独立详情页，默认展示可编辑能力；会话列表作为同页页签保留。使用同一配置表单和既有后端权限，保存能力配置、基本信息和默认模型；无编辑权限时只读。草稿离开保护和保存冲突提示避免丢失修改。助手更新增加可选 expected_revision 与原子版本条件，不改变数据库结构。

## 验收

- [x] 详情默认进入能力配置，同页可切换独立会话列表；四类能力、共享编辑表单、只读权限及保存中状态完成代码审查和回归。
- [x] 本地安装客户端经真实浏览器配置临时私人助手：绑定一个数据连接及一个查询工具、两个知识库、一个 Skill，并启用 Web Search。保存后切换页签再进入仍正确，独立 API 读回逐字段一致；临时助手已停用，正式助手未修改。
- [x] 真实浏览器验证继续编辑保留草稿、放弃修改恢复已存配置；模拟另一编辑者更新后，旧草稿保存返回409，草稿保留，重新加载需明确确认后读取最新配置。
- [x] 客户端45项测试及 TypeScript/Vite 生产构建通过。腾讯云完整后端225项通过；随后修复保存响应读取竞态，最终资源/权限/API定向25项和独立16项检查通过。未把最终定向检查描述为再次完整回归。
