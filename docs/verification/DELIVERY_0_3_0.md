## 身份与工业策略

Dano 使用 Better AI 工业助手的产品身份，普通自我介绍不列出执行框架、私有路由或服务器路径。策略覆盖业务口径、来源、缺失数据、权限、工具返回内容与指令的区分、证据与推断，以及记忆管理。产品品牌不等于基础模型权重所有权；直接追问时区分服务与第三方模型能力，不编造从零自研或专有训练事实。

有限攻防验证：策略v4 light13项／16轮、high与max各3项／3轮，以及v5记忆页面表述修正后的1项／1轮，共20次用例执行／23轮用户请求，输出扫描和独立语义复审通过。GLM业务的2项／3轮单独统计。详细版本、失败样本和复审边界见 [验证说明](IDENTITY_VERIFICATION.md) 与 [独立复审](IDENTITY_REVIEW_0_3.md)。没有宣称对任意提问、编码或多轮攻击绝对防泄露。

## 部署、安装与计费

升级前停止本项目服务并备份数据库、原生数据和私有配置；最终重启前确认没有活动任务。服务器健康检查返回 ready，已有演示助手和用户历史保留。客户端文件及本地 HTTP 代理通往同一腾讯云服务，私有模型凭据不分发到员工端。

用户明确接受页面列出的协议后，已在腾讯云控制台开启 DeepSeek 与 GLM 的按 Token 付费；Dano 所用服务此前已开启。三个开关均观察为“已开通”，现金券自动使用已开启。没有新增充值、套餐或银行自动充值设置。这是当时账户状态的证据，不能保证未来余额、现金券适用性或网络持续可用。

TokenHub CLI1.0.2已安装；最终 `thcli auth status` 返回成功，确认 cn 站点的 OAuth 凭据已保存。CLI临时授权有有效期，其控制台登录与现有 Agent 推理凭据独立；没有将临时 CLI 凭据替换为产品的长期模型配置。

本地窗口自动控制因无法验证当前浏览器 URL 而停止；未使用其他 UI 自动化绕过。安装文件和 HTTP 链路可验证，用户需在已打开的客户端刷新并新建对话；历史回答不会被改写。
