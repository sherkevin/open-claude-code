# MCP 会话审批：连接级一次核验

## 产品规则

手动模式：外部业务 MCP 逐次确认。自动模式：已核验、已授权且当前定义一致的只读工具直接执行；写操作、通用业务动作及未核验工具逐次确认。完全权限仅扩大原有工作区权限，不放宽外部业务写入。平台既有高风险双人审批、任务快照、数据权限、请求限制和撤销逻辑优先。工作区内生成表格/文字不等同于写数据库；文件写入等现有安全策略不在本次放宽范围。

## 实现

- 复用现有 read_only_tools 定义指纹、工具授权和实时 MCP 核验机制，增加连接级核验及版本、核验者、核验依据和审计记录。连接所有者可核验其私有资源；共享连接仅由管理员核验。没有新增资源访问权、自动批准写入或新增第三方依赖。
- MCP 页面提供批量核验，只允许显式勾选经供应方契约及权限核实的工具；不根据名称、远端注解或测试成功自动确认。
- 核验绑定连接版本与工具定义，运行前及执行中重新核验。已使用新核验的连接不能在撤销后回退到旧绑定确认。会话自动审批不再使用旧工作流免确认开关；旧工作流的单独只读核验及权限要求不变。
- 对通用动作、明显写入、任意 SQL/命令入口采用保守排除；它们不得成为会话自动审批工具。服务端行为及权限仍须供应方负责，不能仅凭静态定义证明实现无副作用。
- 华微真实 MCP 当前 describe、query 为结构化目录/数据集查询接口，call 为已发布业务 action 执行接口。已核对当前真实工具定义与业务查询证据；没有擅自签署客户只读核验或更改数据库权限。需连接所有者核实供应方只读契约，选择 describe 和 query，call 保留逐次审批。

## 回归与发布边界

- 后端 tests/test_connection_read_review.py 与 tests/test_harness_mcp_tools.py：56 项通过（含私有/共享权限、核验撤销和版本变化、手动/自动/完全权限、旧免确认标志不再绕过审批、真实合成本地 MCP）。
- 前端审批、MCP、助手配置、业务引导等 8 个测试文件：103 项通过。生产 BASE_PATH=/project/kaiwu/ 完整构建成功。
- 真实客户写工具不作为测试目标；不得对客户业务系统执行写操作来证明审批。上述测试不代表供应方实现或数据库授权已被独立审计，也不是全仓库回归。
