# 会话记忆检索 · Chromium 隔离验收

从工作台打开自己的 Harness 会话，在页头点击“会话记忆”。只有该会话允许使用且已配置独立作用域工厂时，原生文件编辑器下面才出现“检索会话记忆”。仍由用户选择何时同步已保存的记忆，检索结果显示核验过的原文、文件路径和版本。

| 用户操作 / 测试条件 | Chromium 实测 |
|---|---|
| 基线 888dd7e，真实 SDK 工厂可用 | 打开页头会话记忆，新建并保存中文 MEMORY.md 成功。页面没有语义同步和检索入口，保存后无索引写入 |
| 候选，服务默认关闭 | 打开同一入口后原生编辑器可用。等候能力接口实际返回，语义面板未显示 |
| 候选，启用开关但没有工厂 | 原生编辑器可用，语义面板未显示 |
| 候选，显式注入真实 SDK | 新建文件 → 源码编辑 → 保存“备件库存警戒线为十二套。” → 首次检索显示尚无可核验结果 → 显式同步 → 查询“库存警戒线”。命中同一原文与 MEMORY.md · 版本 1 |
| 刷新浏览器，再次打开会话记忆 | 面板重新初始化。用户主动查询回读同一原文和版本。整个流程共 1 次同步、3 次显式查询，0 次模型消息 |
| 向量供应方返回一次 HTTP 503 | 真实 SDK 将写入结果反馈为不确定，产品 API 返回 HTTP 200 / partial。页面显示同步尚未确认，未显示同步完成；浏览器仅发出 1 次同步 |

复验曾在文件保存后出现旧版本组件卸载、用户刚输入的检索词丢失，按钮持续禁用（browser-enabled-final.log，退出 1）。修正后按会话保留输入框，原文件版本变化时隐藏旧结果。最终浏览器回归先输入检索词再保存原文件，验证保存和索引视图刷新后可直接使用该查询。

**工厂准入**。此改动只消费现有 owner-scoped 能力、同步和检索接口，控制由服务端继续实施。隔离服务使用明确启用开关和已验证的私有 SDK 工厂，检索以合成回环向量建立确定性对照。没有真实模型质量、计费、生产工厂或生产上线回执。清空和退役语义沿用原有产品边界。
