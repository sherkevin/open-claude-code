## 背景与用户已经确定的决定

我们是开物平台管理者，华微世纪使用我们的公网平台查询自己的内网数据。华微已经把业务查询封装成 MCP，业务 MCP 在其 Windows Server 2019 上；已有智能体在另一台 Linux 上。客户内网只能主动访问公网。

本次交付一个 Windows 桥接器：Windows 主动连接我方 relay，本机代理调用现有 MCP 并附加客户认证；云端 Edge 提供受保护的公网 MCP URL；我方生成标准 MCP JSON，直接导入现有开物平台。员工使用企业统一入口，客户本机使用固定业务读取身份。

不需要逐员工身份映射、OAuth Token Exchange 或重新实现数据库查询。客户内部 `B/S/channel/userid` 只在 Windows 本机录入。开物 JSON 中的 Bearer 是我方签发、企业／来源绑定且可撤销的集成凭据 K，不能使用客户内部密钥替代。
