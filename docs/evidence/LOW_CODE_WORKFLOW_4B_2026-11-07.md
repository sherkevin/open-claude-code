# 低代码工作流优先级 4B 证据（2026-11-07）

## 范围

本切片把优先级 4A 的工作流契约接入助手详情页面，提供人工设计体验。页面不调用真实模型、业务连接或客户数据。

## 已实现

- `client/src/WorkflowPage.tsx` 提供工作流列表、画布、节点类型面板、节点配置、连线面板、草稿保存、发布、版本回滚和合成测试入口。
- 画布展示智能体、工作方法、知识检索、只读工具、条件、审批和产物节点；编辑器只保存受控标签和 `synthetic` 执行模式。
- 客户可以从默认业务流程开始增删节点和连线；客户端先检测循环，服务端仍是最终校验方。
- 页面明确显示“合成环境”和安全边界，禁止把本地合成结果误认为真实业务执行。
- 助手详情新增“工作流”标签，不改变现有能力配置和会话入口。

- 当前运行中的旧后端没有新工作流接口，未执行服务重启；需要单独批准后才可在网页中端到端操作。
- 不能据此宣称客户低代码平台或生产工作流已经交付。
