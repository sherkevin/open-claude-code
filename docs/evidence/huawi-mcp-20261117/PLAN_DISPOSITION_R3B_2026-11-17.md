## 已冻结的决定

| 审核问题 | v0.6 决定 |
| --- | --- |
| 令牌 `A` 同时被解释为静态平台凭据和短期用户委托令牌 | 用户委托令牌统一为 `AT_user`；平台配置不得包含静态用户 Bearer；现有 `<EDGE_ACCESS_TOKEN>` 仅是无效占位符，不能用于端到端验收 |
| 来源工具允许列表由谁批准不清楚 | 客户本机管理员拥有来源级只读 allowlist 的最终批准权；平台只能签发更窄 grant；身份映射继续取交集 |
| G7a/G7b 缺少可判定测试输入 | 客户必须提供合成或脱敏测试数据包，包括固定查询、预期字段或结果、禁止字段、空结果和失败案例；HTTP 200 不能作为通过依据 |
| 身份映射只有数据结构，没有生命周期入口 | 必须有创建、批量导入或组织同步、修改、失效、撤销、版本递增和审计页面或接口；禁止手改数据库 |
| 合成权限测试和真实数据权限测试混在一起 | HWC-060 拆为 G7a 前合成验收和单独批准的真实数据权限验收 |
| 受控试装与正式交付门禁互相覆盖 | 普通 P1 可以书面接受风险；HWC-028、HWC-059、HWC-061 不能由普通 P1 豁免 |
| SBOM 和扫描标准不客观 | 受控试装固定 CycloneDX 1.5 JSON；SBOM 必须包含组件版本、包 URL、哈希、关系和许可证；Critical 未关闭或 High 无批准人不得进入 G7a |
| Windows 目标机责任不清 | 客户目标 Windows Server 2019 用于最终验收；我方 Server 2019 虚拟机只用于合成回归 |
| `B`、`S` 和渠道身份如何导入不清楚 | 由客户本机管理员通过受控本机步骤导入，不经过平台页面、导出 JSON、普通文档、聊天或日志 |
| 当前能否先让客户试用不清楚 | 新增“本机诊断试用”级别，只验证安装、MCP 导入、认证配置、诊断、卸载；不得表述为平台端到端已通 |

## 仍然开放、不能由本记录关闭的事项

1. 云端接入码、设备身份、来源登记、期望状态、通道密钥、心跳、排空、恢复和撤销尚未形成真实控制面。
2. relay、visitor、Edge、`AT_user` 的 OAuth Token Exchange、身份映射和一次性 `E` 尚未完成真实联调。
3. Windows 提权 helper、命名管道双向认证和低权限服务账户尚未在 Windows Server 2019 上实机验收。
4. 当前没有客户测试入口、测试 tenant/source、合成或脱敏数据包、测试凭据和允许工具清单。
5. 受控试装包尚未完成结构化 SBOM、SCA/CVE、恶意软件、秘密扫描、独立构建比对和正式哈希批准渠道。
6. 尚未取得 Authenticode 证书、客户 Server 2019 测试窗口和客户验收人。
7. 正常停止、强杀、网络黑洞、relay 故障、容量、告警和 SSE 长连接均没有真实 C 段证据。

## 执行原则

1. 先交付可逆的 Windows 本机诊断试用，优先发现客户入口、认证、TLS、DNS 和工具 schema 的真实问题。
2. 每个开发分支只负责一个功能，由项目负责人合并并删除已合并分支。
3. 每完成一个功能必须运行对应测试并新增证据；测试未通过不进入下一关卡。
4. 不碰生产部署、共享服务重启、真实客户数据、真实客户凭据和未授权付费模型。
5. 所有对外结论以 `CLAIM_LEDGER_2026-11-17.md` 的状态为准。
