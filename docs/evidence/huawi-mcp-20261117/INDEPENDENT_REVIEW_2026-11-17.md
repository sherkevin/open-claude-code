# 华微内网 MCP 桥接计划独立审核记录

- 审核对象：`docs/plans/2026-11-17-huawi-kaiwu-mcp-bridge-requirements-and-delivery-plan.md`
- 首轮审核日期：2026-11-17
- 审核方式：业务可用性、安全架构与协议、交付测试与运维三个独立视角只读审核
- 审核边界：未修改业务代码，未部署，未重启共享服务，未使用真实客户数据或真实凭据
- 首轮结论：技术方向正确，但 `v0.1-review` 不应直接审核通过；发现项已进入 `v0.2-review`

## 一、业务与客户可用性审核

| 编号 | 严重度 | 审核发现 | 第二版处置 |
| --- | --- | --- | --- |
| B-01 | 高 | 缺少开物用户/组织到华微 `channel/userid` 的数据范围映射。共享固定身份可能导致多个开物用户看到同一套华微数据，甚至越权 | 新增 HWC-032 和 7.4；正式交付默认逐用户/组织映射；缺失、过期、撤销时拒绝；共享身份只允许有书面范围和期限的试装 |
| B-02 | 高 | 首个试装没有拆开销售查询和尚未确认入口的知识检索，可能被外部依赖阻塞 | HWC-031 拆成 G7a 销售只读试装和 G7b 知识检索与完整 C 段验收 |
| B-03 | 中高 | 只有后端接口清单，没有平台管理员和客户现场可执行的完整操作旅程 | 新增 HWC-033；要求平台页面完成创建连接器、接入码、来源、授权、导入、绑定、测试、暂停和撤销；客户现场只做安装、绑定、导入和诊断 |

| B-05 | 中 | 缺少试运行值班、故障升级、暂停/恢复/撤销责任和面向用户的错误提示 | 新增 HWC-034 和 HWC-047；要求中文错误文案、责任人、升级路径、值班和回滚联系人 |

## 二、安全架构与协议审核

| 编号 | 严重度 | 审核发现 | 第二版处置 |
| --- | --- | --- | --- |
| S-01 | 阻断 | 回环页面会话令牌只防跨站，不是管理员身份认证；任何能访问本机页面的低权限用户可能管理连接器 | HWC-010 和 HWC-035 要求服务拒绝非回环监听；高影响操作要求 Windows 管理员或受 ACL 保护的本机管理通道；页面令牌只做 CSRF |
| S-02 | 阻断 | 诊断接口接受任意工具探测名，可以绕过工具允许列表 | 新增 HWC-036；只允许已保存的已批准只读探测工具；空允许列表禁止工具调用；UI、代理和 Edge 共用默认拒绝交集 |
| S-03 | 阻断 | 云端下发的 `local_host/local_port` 可改变连接器访问的内网目标，控制面攻陷后可成为内网跳板 | 新增 HWC-037；本机目标由客户管理员确认并持久化；云端只能引用 `source_id`；不一致时拒绝整个期望状态 |
| S-04 | 阻断 | MCP 方法没有默认拒绝和工具目录过滤，`resources/prompts/sampling` 等能力可能绕过只读工具范围 | 新增 HWC-038；只允许 `initialize`、`notifications/initialized`、`ping`、`tools/list`、`tools/call`；其他方法返回 403；工具目录取允许列表交集 |
| S-05 | 阻断 | 固定请求头可覆盖协议头或注入转发头 | HWC-011 和 HWC-039 要求首版只接受 `Authorization`；拒绝保留头、重复头、大小写变体；代理先移除入口头再最后写入 |
| S-06 | 阻断 | 控制面未强制 HTTPS；MCP 客户端可跟随重定向并继承系统代理 | 新增 HWC-040；生产 TLS、证书和主机名校验、禁止重定向、显式代理策略；带客户秘密的上游默认必须 HTTPS |
| S-07 | 高 | DPAPI 方案漏掉设备身份和 relay 令牌 | HWC-019 扩展为保护 `D`、relay token、`B`、`S`、`T`，并覆盖轮换、撤销和备份处理 |
| S-08 | 高 | 动态签名的 requestId 生成和防重放要求不明确 | HWC-020 要求密码学安全随机源生成 UUID、UTC Unix 秒、每次重试重新生成；增加重放测试 |
| S-09 | 高 | 上游错误正文可能回显到 UI 或日志 | 新增 HWC-041；只返回稳定错误码、状态摘要、建议和 trace_id；正文只记录摘要或长度；增加秘密和业务正文注入测试 |
| S-10 | 高 | 设备身份是纯 Bearer，没有主机绑定 | 新增 HWC-042；正式交付前支持设备公钥/主机指纹或等价绑定；试装若不启用必须书面接受残余风险 |

## 四、首轮审核共同结论

- 最终目标正确：连接器从华微内网主动出站，开物平台通过 Edge 和中继调用已授权的只读 MCP，不开放客户入站端口，不把客户凭据上传云端。
- `1.0.1` 的 Windows 本机和本地 MCP 验证可以作为受控试装准备，不能证明 C 段已经闭环。
- 受控试装、正式交付和 OpenClaw 全面替换必须分开陈述。
- `v0.1-review` 不通过最终审核；完成第二版修订后进入复审。

## 五、第二版修订状态

`v0.2-review` 已新增 HWC-032 至 HWC-047，并修订 HWC-010、HWC-011、HWC-019、HWC-020、HWC-023、HWC-026 和 HWC-031。复审将重点检查：

1. 身份映射和共享只读身份的边界是否闭合。
2. 本机管理员授权、默认拒绝方法和请求头是否可直接实施。
3. 目标固定、TLS、错误脱敏和设备绑定是否有明确验收。
4. 试装准入、G7a/G7b 和正式交付是否不再循环依赖。
5. 需求与测试追踪、容量和运行监控是否足以支撑企业试装。

## 六、后续状态

第二轮独立复核发现 `v0.2-review` 仍未解决授权主体链、双向 MCP 过滤、Windows 管理员落地、目标重建、原始证据和发布基线等问题，因此未通过。第二轮记录见 `SECOND_ROUND_INDEPENDENT_REVIEW_2026-11-17.md`，当前计划已修订为 `v0.3-review`，仍需第三轮复核。
