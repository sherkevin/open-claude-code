按历史部署记录，华微灵犀的 MCP 身份代理部署在 Linux OpenClaw 服务器上。《HW ERP MCP 开发手册》明确，业务 MCP 由华微现有应用 HwMain 承载。运行该 HwMain 实例的具体主机和操作系统尚未确认；若桥接器须与业务 MCP 同机，应先核对该实例的应用映射和部署主机。
连接与查询流程
桥接器启动后，从华微内网主动连接开物智能体平台并保持长连接。平台有查询任务时，通过这条连接将请求发给桥接器；桥接器以华微授权的业务身份调用对应 MCP 工具，再沿原连接返回结果。华微无需为此开放公网入站端口。
历史部署与现场验证
Linux 代理　历史配置中，SysDevCore 销售测试代理监听 127.0.0.1:18790/mcp；HwBzShow 的销售查询和客访日志代理分别使用本机端口 18890 和 18891。这些回环地址仅供对应 Linux 主机本机访问。
Windows 与销售入口　候选机运行 Windows Server 2019 Datacenter，64 位，Build 17763.9020。该机可访问 https://svr39.bjhwsj.com/SysDevCore/mcp/sales_test 。复核该入口时，初始化请求返回 HTTP 401，响应头标示 Microsoft-IIS/10.0、ASP.NET 和 Bearer 认证。入口呈现 Windows IIS 特征；业务 MCP 进程是否位于该候选机，仍需核对 IIS 应用映射及转发规则。

出站网络与设备注册　请分别给出注册和长连接所需的域名、端口、协议及路径，说明代理、TLS 证书、心跳与断线重连要求，并提供测试设备的注册方式。
MCP 对接　请说明桥接器支持的 HTTP MCP 传输方式、Bearer 凭据配置方式，以及业务调用携带身份头和签名的能力。设备接入码由开物签发，业务身份与只读权限由华微配置。
知识检索与销售查询范围
拟接入知识检索和销售订单查询两类只读工具。销售查询的业务身份、可用工具和字段范围尚未核实；知识检索的服务地址和工具名称也待确认。请开物说明如何分别配置两类查询的 MCP 入口及对应凭据。
