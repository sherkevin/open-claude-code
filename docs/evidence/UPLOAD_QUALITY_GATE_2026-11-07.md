# 文档上传质量闸门（2026-11-07）

## 验收原则

上传返回成功不等于内容质量合格。本闸门要求：

- 文档版本哈希与固定合成夹具一致；
- 文本和表格状态为 `ready` 且有非空分块；
- 检索结果必须包含标准答案中的数字、公式、时区和批次编号；
- 图谱节点和边必须有文档版本来源；
- 没有语义关系模型时，图谱只能标记为 `not_ready`，不能宣称多模态知识图谱完成。
