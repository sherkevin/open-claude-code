# D2.3c1｜Mem0 SDK 自有资源与调用生命周期

基线 a1eb661，独立工作树 kaiwu-mem0-resource-close-20261126。固定 SDK 的 Memory.close 只关闭历史 SQLite，本地 Qdrant 锁与 OpenAI 两个客户端需要由宿主明确释放；未增加新记忆引擎。

薄适配将加载器自有资源绑定到 Mem0SdkBackend。SDK 每次调用与关闭使用同一进程内锁，关闭不会在同步调用尚未返回时释放运输层或向量库；关闭标志永久拒绝后续调用，重复关闭不重放，按身份去重资源，即使单个 close 异常也继续尝试其余资源并明确报告失败。直接注入的旧测试 memory 保持原 close 契约；不会假定外部注入客户端的所有权。进程间宿主锁规则不变。

边界：不是远端请求取消或整个维护批次的停止事务。应用生命周期仍须先停接新任务并等待维护退出，再关闭独立 SDK；未知写入回执及撤权残留对账另做。不自动删客户数据，功能默认关闭，生产闸门不变。

验收结果：后端 53/53，退出码 0（57.50 秒），含 3 个新增专项；真实 SDK 9/9，退出码 0（92.46 秒），增加双次 close、两客户端及 SQLite 关闭、同一持久 Qdrant 路径重新打开并核对其他作用域已有记录。证据目录 /media/data3/dengkw/acceptance/kaiwu-mem0-resource-close-20261126/。两组最终日志及退出码已独立核对。
