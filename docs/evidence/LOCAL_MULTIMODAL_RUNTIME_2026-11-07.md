# 本地多模态运行时证据（2026-11-07）

## 范围

本记录只覆盖学校云开发环境和公开工业图片夹具，不涉及生产部署、服务重启或真实客户数据。

## 运行时

- 本地视觉模型：OpenAI CLIP ViT-B/32，权重位于机器共享模型目录，输出 512 维归一化图片向量。
- 本地文字识别：RapidOCR，输出文字框、置信度和原图坐标。
- 图像处理：原图哈希、最长边受限缩略图、最多 16 个确定性网格区域；向量和文字框均绑定文档版本及区域标识。
- 当前 Python 的 PyTorch 是中央处理器构建，端到端运行显示 `device=cpu`；机器检测到显卡不等于当前进程已经使用显卡。

## 公开样例端到端验证

输入：`fixtures/industrial-public-v2/images/nist-sp80082-scada-fig2.png`。

新建隔离开发数据目录并上传该图片后：

- 文档状态：`ready`；文字页和检索片段正常生成。
- RapidOCR：51 个文字框，1564 个字符。
- 图片向量：512 维，模型为 `openai/clip-vit-base-patch32`。
- 图片区域：4 个网格区域，均生成区域向量和受权限保护的缩略图。
- 图谱候选：4 个 OCR 加规则实体，关系为可解释的 `co_occurs` 同区域共现。

该结果证明本地图片索引链路可以运行，不证明语义实体召回率、关系准确率或客户业务质量。
