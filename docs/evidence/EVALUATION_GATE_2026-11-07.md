# 本地持续评测闸门阶段证据（2026-11-07）

## 已实现

- 新增 `scripts/evaluation_gate.py`：读取暂存、未暂存和未跟踪文件名，标出提示词、检索、路由、运行时、安全、审批、Sub-agent 和客户端聊天等受治理变更。
- 对受治理变更统一重放固定的离线工业合成基准；闸门报告保留夹具标识、比较键、通过任务数、变更文件和证据边界。
- 闸门采用失败关闭规则：只有合成报告明确标记 `synthetic=true`，且聚合通过任务数为正并等于任务总数时才返回 `passed`；状态字段与计数不一致、报告截断或非合成报告均拒绝。
- 闸门不调用模型、客户系统、生产数据、凭据或网络服务；失败时返回非零退出码，不把合成结果当真实性能或客户验收。

## 验证

```text
python3 scripts/evaluation_gate.py --output /tmp/zhixing-evaluation-gate.json
python3 -m unittest examples.test_evaluation_gate
```

本地回归：闸门合成任务 `4/4` 通过；测试覆盖报告写入、变更识别和 `evaluation_required` 标记。
另有回归覆盖“状态显示通过但聚合计数不完整”的失败关闭情形。

## 未完成

闸门尚未接入受保护的持续集成或正式发布系统，也没有真实客户基线、真实模型 Token/延迟、视觉质量或回滚演练证据；这些仍保持待验收状态。
