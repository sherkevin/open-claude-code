# 图片知识索引阶段证据（2026-11-07）

## 已实现并可本地验证

- 知识库图片版本仍保存原始字节、哈希和权限；新增本地图片资产登记表。
- 上传时在服务端使用 Pillow 读取宽高、格式、模式，并生成最长边不超过 `640x480` 的 JPEG 缩略图。缩略图位于受保护的知识库目录，缩略图和原图均经过当前用户权限检查。
- 对栅格图片额外生成最多 16 个确定性网格区域（最多 4×4）。每个区域保存原图坐标、网格位置和最长边不超过 `320x240` 的 JPEG 预览；区域标识绑定 `document_id + version + row + column`，通过 `GET /api/v1/knowledge-documents/{id}/regions` 和区域缩略图接口访问。
- 可解析的 PDF 会额外生成前 12 页的本地页面预览；页面预览只是人工查看的压缩产物，不会被当成视觉 embedding 或图片实体。
- 文档列表、图片元数据接口和知识图谱页面会显示缩略图、尺寸、版本、原始文件、OCR 状态和安全网格预览；图谱返回区域坐标与状态，前端不将区域渲染成视觉实体。
- 图谱接口附带当前可见图片资产清单、区域计数、视觉实体候选和视觉关系候选；每一项都绑定文件版本、区域和来源文本。当前关系明确标记为同区域共现，不冒充语义关系。
- 知识库文本检索命中图片或 PDF 页面时，结果额外返回版本绑定的 `media` 证据：缩略图、页面/网格坐标、文件哈希和视觉模型状态；客户端在检索结果中显示预览并明确“视觉语义待授权模型”，不会把图片预览当成语义召回。
- `server/app/vision.py` 已接入本机共享目录的 OpenAI CLIP ViT-B/32 权重（512 维）和 RapidOCR；模型只从本地路径加载，不在索引过程中下载权重。
- 无文字图片不再因为 OCR 为空而丢失：图片版本可以在没有文本片段时保持 `ready`，依靠视觉向量和图片证据进入知识库；只有普通文本类文档仍要求至少一个可检索片段。
- 检索增强生成（RAG）在混合或向量模式下可用同一 CLIP 空间生成文本查询向量，并召回没有 OCR 文字的图片；结果明确标记为 `visual_embedding`，不把空文本伪装成普通文字命中。
- 在公开夹具 `fixtures/industrial-public-v2/images/nist-sp80082-scada-fig2.png` 上完成一次新应用进程端到端验证：上传状态 `ready`，本地 OCR 得到 51 个文字框，图片向量为 512 维，四个网格区域完成向量索引，并写入 4 个有来源的规则实体候选。
- `server/tests/test_knowledge_evidence.py::test_image_asset_thumbnail_is_local_and_visual_index_is_truthful` 现同时验证有效 PNG 的缩略图、四格区域、版本绑定、元数据、授权访问和 OCR 缺失状态。
- `server/tests/test_knowledge_evidence.py::test_image_retrieval_attaches_version_bound_media_evidence` 验证图片经本地 OCR 进入文本检索后，命中结果携带同一版本和哈希的媒体证据，并可按权限读取缩略图和区域。

## 明确未完成与证据边界

- 当前本地 CLIP 和 RapidOCR 已可用；本机当前 Python 的 PyTorch 为中央处理器构建，因此实际端到端证据为中央处理器执行，不能宣称使用显卡。机器虽检测到显卡，后续需在独立环境安装并验证匹配的显卡版 PyTorch 才能切换。
- 网格区域是有界的版面预览，不是物体检测或语义分割；缺少本地模型时区域状态保持 `needs_model`，模型可用时只写入向量和来源绑定的候选，不把坐标切片冒充实体。
- 图片 OCR 组件缺失时，版本保持 `needs_ocr`，不可进入文本 RAG；缩略图仍可在权限范围内预览，便于人工补充 OCR 或后续重建。
- 当前图谱的图片实体来自 OCR 加确定性规则，图片关系仍是同区域共现；TokenHub 视觉模型适配器已单独通过真实本地回环线路探针，但模型候选尚未自动写入生产知识图谱，因此语义实体和语义关系验收仍未完成。
- 当前 `media` 仍是检索命中后的证据挂载，不是图片向量召回；没有 OCR 文本命中的图片不会被文本检索主动召回。
- 要完成语义视觉图谱，需要把已验证的 TokenHub 视觉模型调用作为显式、可审计的索引阶段，并用公开或脱敏工业图片标注集验收实体召回率、关系准确率和引用质量；当前不把一次线路可调用性探针当成质量验收。
