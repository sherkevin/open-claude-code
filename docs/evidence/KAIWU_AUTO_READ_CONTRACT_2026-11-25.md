# 自动审批：后台可信接口契约

普通业务用户仅切换会话手动/自动模式。自动模式中的已登记可信查询契约、当前授权和远端工具定义同时匹配时，不再逐次弹窗；手动模式、写入、通用动作、未知及不确定工具仍逐次确认。没有为普通用户新增配置任务。

实现复用现有会话审批、工具授权、参数约束及远端定义复核。服务运营者管理私有 data_dir/trusted-mcp-read-contracts.json；不存在、权限不符、过期或不匹配时默认无自动批准。条目绑定连接身份（连接/账号/版本/路由/认证配置摘要）和每个实际定义的 SHA-256，并有登记时间及截止时间。人工高级设置可覆盖默认规则，包括全部撤销。历史工作流标志不重新获得会话免审批权限。不根据工具名称、模型判断或远端只读注解单独放行。新供应方或变更的来源需要后台建立可信契约，不意味着所有第三方 MCP 自动获得信任。

华微：依据真实来源已发现的结构化接口契约和先前真实只读调用证据，平台运营策略仅登记当前实际连接的 describe/query 定义，call 不纳入。2026-11-17 的原始接入说明以只读查询为目标，未证明全部数据权限已核验；这不是客户对数据库无副作用的签字或独立服务端实现审计。现有客户身份、数据授权、工具范围、凭据及业务系统配置不变。规则截止时间不超过现有集成有效期。来源与工具定义变更时按原平台控制及实时定义复核拒绝沿用。

验证：4 项新增后端测试通过（包含本地真实 MCP 自动/手动审批、写工具不放行、身份/版本/定义变化及撤销）；72 项前端相关测试通过，生产路径构建通过。不得以客户写入操作作为验收测试。
