# 给正在作答的同一轮工程任务补充条件

普通成员在工程窗看到首段后，可以把新条件补给当前轮。开物显示执行器是否收到，用户可以对照本轮最后的回答，判断模型是否采用。

## 从正常入口操作

打开自己的会话，点工具栏的「Codex 工程任务」。发送“给我一条核对订单导出范围的建议。先说第一步，再说明需要选哪个日期范围。只用文字，不操作文件。”。看到“先打开订单导出的筛选条件。”后，在「补充要求或下一轮任务内容」输入“补充一个条件：只看上个月，请据此说明日期范围。”，点「补充到当前任务」。

仅打字会留在当前窗口。要换题，可点「取消当前任务」，等界面显示「已取消」，再点「发送任务」。回访时，从首页「继续工作」按会话名选回，打开工程窗看补充回执，展开「Codex 工程回执历史」看最终答复。各场的运行编号仅用于事后核实。

| 入口 | 见首段后，怎样改变原任务 | 实际发生的事 |
|---|---|---|
| 开物 6138a93 | 能写下一轮草稿，只有停止后另问或等原轮自行结束 | 停后另问对照为同一线程、两轮，第一轮中断、第二轮完成 |
| 开物 9d7ae68 | 输入文字后显式点击「补充到当前任务」 | 普通成员网页经本人的原工程线程和轮次送达。输入框同时保留另问路径 |
| 原生 Codex 0.165.0 终端 | 在仍有输出时输入并按 Enter | 上轮已验收的对照为 1 个原生轮次。原流尚未结束，第二条用户输入已到提供方 |
| 原生 DeepSeek Harness 0.2.2-rc.1 网页 | Enter 默认排队。选择 Steer queued message 追加到当前轮 | 同轮引导样本为第 1 轮的第 1、2 步。默认排队样本为两轮，每轮 1 步 |

每行 1 个独立空工作区和 1 个普通成员会话。浏览器与固定原生 Codex 都实际运行。回环合成提供方读取实际收到的第二条输入，遵从场从中取得条件，另一场故意忽略。列中的“收件”统计工程推理 HTTP 请求，单位均为次。

| 开物用户场景 | 启动原生轮次 / 原生补充 / 模型收件 | 界面与答案 |
|---|---:|---|
| 首段后补充，模型采用 | 1 / 1 / 2 | 回执显示“已送达目标轮次的执行器”。本轮答“日期范围设为上个月的第一天到最后一天。” |
| 同样送达，模型忽略 | 1 / 1 / 2 | 回执同样显示已送达。本轮答“采用默认筛选范围即可。” |
| 旧轮先结束，新轮已在作答 | 2 / 0 / 2 | 延迟旧轮的补充请求直至新题已到模型。旧轮回执显示“目标轮次已无法接收，补充要求未送达”，新题、新答均无旧条件 |
| 原生已收，网页没收到回包 | 1 / 1 / 2 | 断网时原输入仍在，显示“送达情况未知”。全关 Chromium，再从首页重开，原编号变成已送达 |

| 明确停止后另问 | 2 / 0 / 2 | 第一轮已取消，第二轮已完成，原会话中能看到两轮的输出 |

上述 6 场回访期间新增工程提交和模型收件均为 0 次。三个实际收到原生补充回执的样本中，“点击到原生确认”分别为遵从 281.069 毫秒、忽略 227.137 毫秒和回包丢失 184.158 毫秒。最后一项在服务侧采到，用户当时看见的是送达未知。每种条件仅 1 场。

第一次验收的候选 2e842a6 在断网后隐去了补充回执，只剩通用网络错误。这场浏览器脚本退出 0，检查网页语义的独立断言退出 1。修正后的 9d7ae68 在同一故障下保留待核编号与原输入。断网时回执区只显示本人的待核编号和目标轮次。浏览器关闭后能核对编号；尚未送出的草稿正文只留在原窗口。

## 固定原生协议、权限与重试

固定版 App Server 的 `turn/steer` 接收既有 `threadId`、`expectedTurnId`、一条文本输入和可选的客户端编号，原生应答含 `turnId`。宿主在发出前登记客户端编号、文本摘要和“待核对”。只有原生返回的轮次等于目标轮次才记为已送达。超时或应答畸形保留未确认。重复编号与目标、摘要一致时只读已有回执。每个工程绑定保留最多 256 个投递编号，达到上限后拒绝新增；回访列出最近 8 条。界面不会将未确认记录自动补发。

服务端沿用原普通会话的用户、可用助手、运行模式和宿主限制，仅向持有此活动进程的宿主发送文本。独立隔离 API 在四种身份下各运行查询、补充、取消 3 个操作，其他成员与换属后的原成员均得 404，已停用账号旧会话得 401。新所有者只看到空列表，对旧轮补充或取消均得 409。12 个操作新增原生启动、补充和取消均为 0 次。换属由测试夹具模拟。另有 5 个受控 Chromium 撤权场景，界面均隐藏了正文、输入和编号。

本轮沿用既有工程试点、只读工作区和审批策略。没有新增工具权限。模型可以在同一轮内再次推理。此处实测的单轮补充需要 2 次模型收件，没有真实供应商账单。
