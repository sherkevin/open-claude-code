## 2. 实现范围

- `Settings` 新会话默认 `harness`；显式 `claude` 保留兼容和回滚。数据库旧会话迁移缺省仍为 `claude`，原生会话标识不互换。
- 新 Harness 缺省推理档位为 `high`，旧 Claude 缺省为 `medium`；显式配置不降级。旧库优先恢复已记录的模型和档位，未记录才使用旧缺省；不改已记录的模型和档位。旧快照缺失供应商指纹时，只从当前配置向前补齐，不能据此证明历史供应商身份。无独立目录的兼容条目保留旧/新两个默认档位，防止升级或回滚使原选择消失。
- 未配置运行环境返回明确错误，不自动扫描安装目录、加载宿主凭据或切回 SDK。前端不能指定执行器或启动路径。
- 聊天页按会话返回值展示 DeepSeek Harness、Claude Agent SDK 或“待确认”，不从模型名推断框架。
- 附件在宿主端授权、读取稳定字节快照，再通过字面文本或编码图片发送。复用既有解析器处理 PDF、DOCX、XLSX；静态图片使用官方图片协议，不把 OCR 文本冒充视觉理解。
- 文件必须属于用户及当前会话允许的范围。路径每级拒绝符号链接，文件拒绝硬链接、异常所有者、大小/类型不符和读取期间替换。当前任务、用户、助手、文件绑定及内容摘要在发送与完成边界复查。
- 原生历史按宿主收据复核：旧附件删除、撤权、绑定变化或同长度字节替换后，不能继续使用私有旧副本。阻断后要求处理权限问题或新建会话，不重放旧业务操作。
- 来源登记保留原件链接、SHA-256、解析方式与页/工作表信息，继续使用原下载权限；图片证据不会被描述为已完成识别或实体抽取。
- 解析和内容哈希不持有全局数据库锁。附件监控允许合法的人工审批等待；取消和撤权会中止本轮，不把正常等待当失败。

## 3. 明确的支持上限

| 项目 | 本批限制 |
| --- | --- |
| 每轮附件 | 最多 10 个，单文件 10 MiB，总计 20 MiB |
| 文本与文档 | UTF-8 或带 BOM 的 UTF-16；既有受支持文本类型及 PDF/DOCX/XLSX；单份解析文本 256 KiB、每轮总文本 512 KiB；超限拒绝，不静默截断 |
| 图片 | 静态 PNG/JPEG/WebP/GIF；单图 5 MiB、总图 10 MiB，单边不超过 10,000 像素且不超过 1,000 万像素；拒绝动画、坏图和伪造格式 |
| 原生历史附件复核 | 最多 200 个唯一文件、累计 64 MiB、1,000 个含附件运行；重复引用去重，超限明确拒绝 |

这不是解析器的操作系统级沙箱：扫描 PDF 仍依赖既有本地 OCR，解析失败或没有可用文本会明确拒绝。官方运行时仍可能向模型展示当前工作目录和会话私有附件副本路径提示；没有发送上传原件路径，也没有开放任意文件读取或 URI 下载工具。撤权可以阻止后续调用和返回，但无法收回此前已发送给模型的资料。

运行中每 250 毫秒复核的是授权和文件元数据，不是持续全文件哈希。内容摘要在准备、投递、结束及下一轮恢复后、发送新提示和复用历史调用模型之前验证；官方会话恢复本身不发起新推理。取消关闭本地传输和执行进程，不保证供应商立即停止已经接收的推理；既有同步解析线程不能被硬终止，返回后清理其临时快照。
