# 腾讯云受控预览性能观察（2026-11-13）

## 范围

本记录是对受控预览入口 `https://119.45.112.102/zhixing/` 的只读性能观察。学校云仍是项目开发、联调和验收的唯一事实来源；本记录不代表腾讯云生产验收，也没有修改腾讯云代码、配置、数据或服务。

## 公网重复请求

通过不使用本机代理的 HTTPS 请求重复测量五次，结果如下：

| 请求 | 返回大小 | 首字节时间范围 | 总时间范围 | 观察 |
|---|---:|---:|---:|---|
| HTML `/zhixing/` | 640 字节 | 0.089–0.100 秒 | 0.089–0.100 秒 | 稳定 |
| JavaScript 主包 | 658,716 字节 | 0.105–0.648 秒 | 0.785–2.517 秒 | 传输量大，波动明显 |

## 腾讯云主机本机对照

通过只读 SSH 在腾讯云主机本机测试项目服务：

- 主机为 8 个中央处理器，内存 30 GiB，可用内存约 21 GiB，无交换分区使用。
- 根磁盘 99 GiB，已用约 40 GiB（43%），可用约 55 GiB。
- 负载平均值为 `0.16 / 0.29 / 0.44`；连续 `vmstat` 观察中中央处理器空闲 91%–99%，输入输出等待为 0%。
- 本机前端静态资源总响应约 0.0002–0.0043 秒；本机健康接口约 0.0015–0.0056 秒。
- 这说明当前时点没有看到中央处理器、内存容量、磁盘容量或本机服务处理能力已饱和的证据。

## 结论与限制

当前页面打开慢更符合“静态资源未压缩，加上公网传输路径波动”的解释，不足以支持立刻扩充中央处理器或磁盘容量。磁盘输入输出的长期百分位、网卡带宽和腾讯云实例监控仍未取得；本机快照也不能代替高并发或登录后真实模型任务测试。

如果用户说的“慢”是点击发送后等待模型首段文字，则需要另外记录 `runtime_ready_ms`、`first_model_event_ms`、`first_text_ms` 和完整响应时间。当前健康接口很快，不能据此推断上游模型推理很快；若实际调用远程模型服务，增加腾讯云中央处理器或磁盘通常不会降低上游排队和生成时间。
