# 会话问题反馈及定时智能体

## 目标与对标

本轮交付：会话右侧问题反馈、反馈管理与日志定位、定时任务调用 MCP、定时任务分派 Harness 子智能体、每日/每周周期执行。参考现有对标矩阵 H14，复用既有会话、任务队列、MCP 和子任务执行器，不引入新的第三方调度框架。
- DeepSeek Harness 官方 feedback: https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/feedback/README.md ，会话反馈和逐消息反馈与模型输入分离。
- DeepSeek Harness 官方 schedule: https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/user/guide/schedule.md ，持久任务、周期执行、错过仅补最近一次、IANA 时区及关联会话。
- Codex 官方工作流说明: https://developers.openai.com/blog/mastering-codex-remote-for-engineering ，/feedback 关联当前会话。
- 本轮不是全功能对标完成。仍需独立对标验收全局周期任务管理、编辑/暂停/恢复、立即运行、更多规则/RRULE、模型创建管理计划任务、新会话执行目标及反馈分类、逐消息快捷入口和处理通知。

## 实现

反馈按钮在会话头部右侧。提交者主动选择当前轮次、已加载消息或整个会话，描述必填，最多 3 张截图（PNG/JPEG/WebP，4 MiB/张，8 MiB 合计）；服务器验证实际图像、解码像素和大小，重编码为 JPEG 去除元数据。仅提交描述、图片和用户选择的关联 ID；不自动上传聊天正文、参数、业务结果或屏幕内容。后台只有工作台管理员可读取提交内容及限定的状态事件、查看截图、标记处理状态。原会话数据权限不扩大。反馈默认 90 天后逻辑清理；现有数据库备份按原留存制度管理。反馈不进入模型上下文；无外部群转发。反馈 POST 支持同一请求编号防重。

定时任务新增 execution_mode=agent，仅适用 Harness 会话，原文字任务及旧客户端默认 text，不静默改变已有计划的执行权限。到期任务使用原有持久 FIFO 和真实运行执行器，当前会话/助手权限、工具审批及高风险策略不变，自动模式仅放行可信只读业务工具，写操作仍需审批。真实子任务继承原父任务授权与已有并行数量限制。每天/每周规则按浏览器 IANA 时区和首次日期/时间；每次生成独立的 occurrence ID 与运行历史。已错过多个时点只补最近一个，重叠时跳过，不堆积；不存在的夏令时本地时刻跳过，重复时刻取较早一次。上次失败/取消/中断或队列报错时暂停未来周期；用户可取消并重新创建计划。取消周期会取消尚未启动的计划实例，已经启动的轮次仍使用原会话停止操作。依照原消息队列策略，前序失败可能需要用户恢复队列；不自动重放已执行的业务动作。
