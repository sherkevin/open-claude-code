# 2026-11-25｜逐回答快捷反馈

## 实现及复用

基线 d392c2c，独立工作树 kaiwu-feedback-message-20261125；与生产基线核对并行且无同模块工作冲突。参考固定官方 Harness packages/feedback/message-feedback 对逐回答反馈不进入模型上下文的约定；复用既有企业反馈 API、授权、幂等、管理员处理与本人历史，避免双存储和外部反馈共享。

已持久化的助手回答增加「反馈」快捷入口，打开同一个会话反馈弹窗并预选确切 message_id；打开不会提交。若目标较早或随后离开当前分页，保留显式选中的本会话消息选项，禁止打开不属于当前会话或非助手回答的快捷目标。既有会话按钮保留；关闭后重新打开使用新的目标和请求号，不带入上一次草稿或回执。用户仍可选择关联范围、输入说明和可选截图。不是新增逐消息评分系统，不发送遥测，不触发模型。

复用 data3 下既有依赖、真实 Chromium、FastAPI/SQLite 和 FakeRuntime。浏览器测试先通过测试运行器产生一条合成回答，随后使用真实 UI 提交反馈；无真实模型、客户数据、客户工具调用或生产写入。证据 /media/data3/dengkw/acceptance/kaiwu-feedback-message-20261125/。
