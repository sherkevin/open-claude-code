# D2.2｜Mem0 单宿主互斥及有界查询回退

基于 fd7df1c，独立工作树 kaiwu-mem0-single-writer-20261126。复用 Mem0DerivedIndex、NativeMemorySourceReader 和宿主权威快照；新增薄宿主入口 Mem0Host，不新建记忆引擎、调度器或模型工具。默认关闭，未挂接生产。

- 必须显式注入已授权的 backend。关闭时不创建锁、不触发后端。固定 data_dir 下的独立文件以 Linux flock 实现同宿主协作进程的非阻塞互斥；禁止符号链接、非普通文件、非当前宿主用户拥有的文件、多硬链接及不符合 0600 的权限。保留锁文件，不通过删除锁文件解除锁定。
- 同一 data_dir 内单写；查询与同步互斥，忙碌时拒绝，不排队重试。不同 data_dir、不同机器或不遵守此入口的进程不在锁保护范围内；部署必须保证专有后端及固定宿主目录。
- sync 只供明确维护调用；lookup 至多一次适配器检索，不自动同步、清理或写入。作用域仍由宿主派生，运行内必须绑定实际 run。
- 完整已核验命中正文默认最多 16384 UTF-8 字节，可配置 1..131072。超过预算、准入失败或索引不可用时返回显式 fallback，无命中正文；不返回原始供应商异常。verified 空命中不代表权威记忆为空。字节上限不是 token、调用时间或货币硬预算；最终渲染及调用方还需复核总上下文预算。
- 真实供应商 I/O 取消/超时、同步期间撤权后的残留清理、生命周期及显式用户授权线路仍是后续启用门槛；本入口未提供分布式锁、成本硬限制或实际产品上下文注入。
