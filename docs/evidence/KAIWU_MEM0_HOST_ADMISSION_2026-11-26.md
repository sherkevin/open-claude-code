# D2.1｜Mem0 宿主授权与已发布快照准入

基线 16111e5；独立工作树 kaiwu-mem0-host-admission-20261126。继续使用固定 Mem0 2.2.1、Qdrant 1.20.0 及原 NativeMemory 权威快照，不新增索引引擎、不开放模型工具、不安装到生产。

- NativeMemorySourceReader.current_scope 仅从已发布且归属一致的快照记录派生作用域，不初始化、不迁移、不批准记忆。
- 保守拒绝非空或无法证明为空的初始迁移，即便后来人工编辑了部分文件，也不自动批准旧内容。
- 校验用户启用、会话未归档、Harness 运行类型、助手使用权限、发布记录、摘要、原生代次和版本。运行内调用必须匹配活动 run 的完整 memory_binding，运行外拒绝忙碌会话。
- 读取权威快照前后重核权限与绑定；适配器在后端查询后重新读取权威快照，拒绝已撤权或过期的命中。未提交的模型提案不进入索引，批准但未正式提交也不进入。
- 这是宿主准入小切片，尚无实际产品调用路径。跨进程单写、索引过程中撤权后的派生数据清理、调用限额、最终上下文注入预算、用户授权与实际 embedding 线路仍需在启用前验收。不得把读前后核验当成对外部向量写入的原子授权。
