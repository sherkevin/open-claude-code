# 2026-11-25｜反馈处理说明发布及本人可见验收

## 范围与复用

沿用开物既有 FastAPI、SQLite 企业反馈记录、React 反馈页面及固定 Harness message-feedback 的不唤醒 Agent 原则。原候选工作树 kaiwu-feedback-resolution-20261125 从 12ce346 开发，本次接续已存在的候选改动，在核对工作树及活动任务后修正测试导航，基于最新主线 22487b2 重放并验收。不新增外部反馈服务、遥测、客户业务写入或模型权限。

- 管理员可显式发布处理状态及最多 2000 字的提交者可见说明；发布前提示不得包含内部日志、凭据或其他用户信息。该提示并非自动秘密检测或 DLP 保证。
- 本人反馈历史显示处理说明；只按所属会话与用户读取，不返回管理员诊断日志或截图。其他用户和管理员不能借此本人查询接口读取他人的历史。
- 管理端编辑带 expected_updated_at 乐观版本检查，陈旧编辑返回 409；旧客户端只更新状态时保留原说明，明确清空并发布则撤回说明。数据库仅增加 resolution_note 列，保留原数据。
- 浏览器测试先展开工作空间管理，再点击问题反馈；修复的是测试路径，不修改生产导航。此前首次浏览器失败因临时路径过长，第二次因菜单折叠导致定位超时。本轮采用 data3 短临时目录。第一次 rebase 缺少提交者身份失败，确认原提交仍存在后在同一独立工作树中中止并用命令级身份重做，未修改全局 Git 配置。
